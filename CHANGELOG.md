# Изменения VCTS

## 1.0.0-beta.1

- Компиляция TypeScript в LuaJIT Lua с путями модулей VoxelCore.
- Типы API, скриптов, компонентов, генераторов и XML-экранов.
- Шаблоны модов и отдельных игр, CLI и меню в терминале.
- Watch, диагностика, подключение внешних Lua API и установка паков.
- Проверки SDK и штатного runtime без локальных исходников движка.
- Воспроизводимый архив и проверка установки из него.

Проверена macOS ARM64 с VoxelCore 0.32.1. Другие платформы пока не проверены.
