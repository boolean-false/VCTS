# История изменений

## 0.15.0 — VCTS integration

- TypeScript preview, CodeLens and interactive sessions.
- Live compilation of unsaved TS documents via the workspace VCTS toolchain.
- Lua diagnostics mapped to TS source lines; temporary builds are cleaned up.


## 0.14.0 - 2026-10-01

- Поддержка Kompot 1.2.0: обновлены типы `State:patch`, `State:update_field`, `K.copy` и `K.form`.
- Добавлены подсказки параметра `hook_diagnostics` для игрового интерфейса и превью.
- В превью Kompot 1.2.0 доступна подробная диагностика порядка хуков с ожидаемыми и фактическими вызовами.

## 0.13.0 - 2026-10-01

- Lua-превью использует IBM Plex Mono из темы Kompot; растровый `normal` остаётся доступным по явному запросу.

- Общий `K.Shape` из Kompot 1.1.0: прямоугольник, круг/капсула, скруглённые и срезанные углы, пиксели и проценты.
- Независимые размеры четырёх углов; превью рисует фигурные фоны, внутренние рамки, тени и вложенные маски `clip`. Покрытие срезов и теней сверяется с игровым растеризатором.
- Подсказки конструкторов `K.Shape`, размеров углов и `focus_shape`, а также `KompotCorners`, `K.rounded_corners` и `focus_radius`.
- Старые вызовы с одним радиусом, таблицами углов и прямоугольным `clip()` сохраняют совместимость.

## 0.12.0 - 2026-09-28

- Lua 5.4 входит в расширение: превью и интерактивный режим работают без системного Lua и настройки PATH.
- Аннотации подключаются по зависимости `kompot` даже до установки пака; установленная версия типов имеет приоритет.
- Пользовательские библиотеки и плагины LuaLS сохраняются. Зависимости и установка Kompot отслеживаются автоматически.
- Добавлен выбор каталога паков из превью с сохранением настройки для проекта.

- Превью поддерживает `M:rotate`, `M:scale`, точки опоры, вложенные преобразования и обрезку.
- Добавлено рисование изображений на Canvas с углом, масштабом, прозрачностью и выбором UV-региона.
- `K.on_frame` продолжает кадровый цикл интерактивного превью до удаления компонента.
- Перетаскивание захватывает указатель за границами холста; Escape и потеря фокуса отменяют захват.
- Типы LuaLS обновлены для преобразований, Canvas и событий перетаскивания с координатами родителя и скоростью отпускания.
- Для `M:draggable` используется единый `on_event`; `ItemSlot` получает `on_drag_event` с теми же фазами.

## 0.11.0 - 2026-09-30

- Шрифты TTF/OTF измеряются и рисуются через FreeType. Высота строк, базовая линия, пробелы и шаг моноширинного текста соответствуют текущему VoxelCore.
- Добавлена поддержка растровых PNG-шрифтов: встроенного `normal`, сторонних шрифтов и цветных глифов.
- Метрики передаются в Lua для размеров элементов, переносов и обрезки. Интерактивное превью измеряет новые символы без сброса состояния; обновление ресурсов перезагружает шрифты и метрики.
- Убраны ручное смещение текста и браузерная подмена при ошибке загрузки шрифта.
- Отображение проверено сравнением пикселей с игрой на сторонних шрифтах. Добавлены проверки порядка `background` и `padding`.

## 0.10.1 - 2026-09-30

- Добавлена официальная иконка Kompot для списка расширений и Marketplace.
- VSIX содержит ресурсы иконки, лицензии и истории изменений для Marketplace.
- Исправлено обновление программных холстов при изменении пикселей внутри изображения.
- Типы LuaLS синхронизированы с текущим Kompot, включая `K.text.version`.
- Проверена поддержка новых анимационных примеров ядра; описаны ограничения превью и порядок публикации.

## 0.10.0 - 2026-09-29

- Превью рисует текстурные фоны `nine_patch` из PNG и процедурных растров, включая границы, повторение, масштаб и тонирование. Отсутствующие PNG скинов отмечаются в диагностике.
- LuaLS аннотации синхронизированы с актуальным Kompot: `K.nine_patch`, `K.raster`, `M:background_image`, настройка `skin` и игровые компоненты UI.
- Автодополнение использует актуальный атлас `kompot_ui_icons`, предлагает источники для `K.nine_patch` и больше не предлагает удалённые встроенные акценты.

## 0.9.0 - 2026-09-29

- Расширены LuaLS аннотации публичного API Kompot: базовые компоненты и их свойства, методы `Modifier`, состояние, прокрутка, темы, цвета, анимации, превью, `App`, поля ввода и встроенная дизайн система `kompot:ui`.
- При активном LuaLS Kompot Lens убирает дублирующиеся статические дополнения, всплывающую документацию и подсказки параметров. Остаются сниппеты блоков, данные проекта и переход к реализации.
- Добавлена проверка соответствия аннотаций экспортируемому API и синхронизации типов в VSIX с паком Kompot.

## 0.8.0 - 2026-09-29

- В VSIX включён Kompot addon для LuaLS: определения типов контейнеров и разрешение `require "pack:module"`.
- В доверенных проектах Kompot расширение автоматически добавляет недостающие настройки LuaLS в конфигурацию рабочей области. Уже заданный LuaLS plugin и библиотека сохраняются.

## 0.7.1 - 2026-09-29

- LuaLS (`sumneko.lua`) объявлен зависимостью расширения и VSIX-пакета.

## 0.7.0 - 2026-09-29

- Добавлены короткие сниппеты `kcol`, `krow`, `kbox`, `ktext`, `kimage` и `kspacer`.
- Дополнение `K.Box`, `K.Row`, `K.Column` и `K.FlowRow` вставляет блок с дочерними элементами.
- Свойства раскладки `K.Column` и их значения доступны в дополнении.

## 0.6.1 - 2026-09-29

- Удалена песочница Lua из панели превью. Для быстрой проверки используется `K.preview` в модуле проекта.

## 0.6.0 - 2026-09-27

- Шаблон UI-модуля использует встроенную фирменную дизайн-систему `kompot:ui`.
- Превью и автодополнение проверяются на Kompot UI без отдельного пака `kompot_contour`.

## 0.5.0 - 2026-09-27

- Превью по умолчанию обновляется после сохранения Lua-файла. Обновление при наборе доступно через `kompot.previewUpdateMode: "live"`.
- При ошибке пересборки сохраняется последнее успешное превью текущего файла.
- Позиция прокрутки остаётся на месте при обновлении, смене масштаба и интерактивных кадрах.

## 0.4.0 - 2026-09-27

- Подсказки значений сразу после `=`: варианты свойств, флаги, цвета темы, модификаторы, стили и иконки.
- Цвета в `CT.theme().colors` и других дизайн-системах берутся из соответствующей темы.
- Алиасы `require` разбираются без комментариев и строк; учитываются объявления до курсора и простые копии алиасов.
- Подсказки и наведение больше не принимают методы посторонних объектов за модификаторы Kompot.
- Исправлен диапазон замены подсказки в строках с кавычками; добавлен вызов дополнения по `=`.

## 0.3.0 - 2026-09-20

- Превью размещено в правой боковой панели рядом с кодом. Оно больше не создаёт вкладку редактора или дополнительную колонку редакторов.
- Кнопка в заголовке Lua-файла открывает эту панель. Требуется VS Code 1.106 или новее.

## 0.2.0 - 2026-08-10

- Кнопка превью в заголовке редактора появляется только у Lua-файлов с `K.preview`.
- Превью открывается вкладкой в той же группе редактора вместо создания второй колонки; кнопка **К коду** возвращает к исходному файлу.

## 0.1.0 - 2026-08-02

- Первое расширение Kompot Lens для VS Code.
- Превью `K.preview` рядом с Lua-кодом с обновлением при наборе, масштабом, вписыванием в панель и интерактивным режимом.
- Дополнение, документация, подсказки параметров, переход к определению и CodeLens для API Kompot.
- Диагностика ошибок превью и образцы цвета для `K.hex`.
- Упаковка в VSIX без зависимостей времени выполнения.
