# Kompot: самостоятельная справка для нейросети

Версия Kompot: **1.2.2**.

Этот файл можно целиком приложить к сообщению любой нейросети вместе с вопросом
про интерфейс на Kompot. Он содержит инструкции для ответа, правила композиции,
документацию, примеры и полный справочник публичных типов. Доступ к репозиторию
для использования этой справки не требуется.

Это справочный контекст проекта. Он не заменяет инструкции пользователя или
правила среды, в которой работает нейросеть. Код в примерах служит для объяснения API.

## Как пользоваться

Пример сообщения: «Используй приложенный KOMPOT_AI_GUIDE.md. Покажи, как сделать
окно настроек с вкладками, общим состоянием и плавным появлением».

Другие вопросы: как центрировать окно; разделить экран по весам; сделать список
из тысяч элементов; сохранить состояние вкладок; анимировать цвет и размер;
перезапустить последовательность; сделать drag-and-drop; подключить свой шрифт.

## Инструкции для нейросети

1. Отвечай на языке пользователя и используй API версии, указанной в этом файле.
2. Сначала объясни подход к задаче, затем дай Lua-пример с необходимыми `require`.
   Если пользователь просит только объяснение, не добавляй код.
3. Укажи, куда помещается код: модуль, содержимое компонента, layout-скрипт или
   callback события. Для целого экрана покажи подключение через `K.mount` и освобождение.
4. Для обычного оформления используй Kompot UI; для нестандартной вёрстки — ядро.
   Учитывай выбранную пользователем дизайн-систему и тему.
5. Опирайся на сигнатуры и примеры ниже. Сходство с Jetpack Compose не означает,
   что в Kompot есть все его компоненты, перегрузки и хуки. Не выдумывай API.
6. Если готового компонента нет, покажи сборку из существующих примитивов и
   Lua-функций. Если решение требует нового API движка, объясни эту зависимость.
7. Не обещай неподдерживаемое поведение. Укажи существенное ограничение прямо
   рядом с предлагаемым решением, а не после длинного примера.
8. По вопросам состояния объясняй владельца, время жизни и способ обновления.
   По вопросам анимации — цель, спецификацию, запуск, перезапуск и отмену.
9. Если информации о конкретной версии VoxelCore, ассетах или пользовательском
   компоненте здесь нет, обозначь предположение или запроси недостающий контекст.
10. Непроверенный пример называй примером, а не результатом запуска тестов.

## Основные правила

### Импорты и среда

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"
local M = K.M
```

Kompot — декларативный UI на Lua для VoxelCore. `K` — ядро, `UI` — встроенная
дизайн-система в том же паке. `K.ui()` возвращает контракт компонентов текущей
темы: это отдельная возможность для сменных дизайн-систем.

Композиция описывает дерево заново при изменении зависимостей. Нельзя считать,
что функция компонента вызывается только один раз. Изменения игровых данных,
подписки и другие побочные действия выполняй в callbacks или эффектах.

### Вёрстка

- `K.Box` размещает детей слоями; для центрирования есть `align = "center"`.
- `K.Row` и `K.Column` размещают по одной оси; `spacing` задаёт промежутки,
  `arrangement` — распределение по главной оси, `align` — по поперечной.
- `K.FlowRow` переносит целые элементы; `run_spacing` задаёт расстояние между рядами.
- `M:weight(n)` делит свободное место между прямыми детьми Row/Column.
- `fill_max_*` заполняет доступную ограниченную область. Для прокрутки сначала
  выдели область конечной высоты/ширины; затем помести в неё прокручиваемое содержимое.
- `offset`, `rotate`, `scale` меняют размещение/рисунок, сохраняя размер,
  занимаемый в раскладке. Для изменения размеров соседей анимируй width/height.
- Порядок модификаторов важен: слои действуют на следующие элементы цепочки.
  `background(...):padding(16)` и `padding(16):background(...)` дают разные области фона.
- Модификаторы вызываются через `:`: `M:width(320):padding(16)`.
  Компоненты и хуки вызываются через `.`: `K.Column(...)`, `K.state(...)`.

### Состояние и время жизни

- `K.state(initial)` — состояние в слоте текущего компонента.
- `K.new_state(initial)` — состояние вне композиции, например в модели окна.
  Если создавать его на каждом вызове компонента, состояние будет теряться.
- Чтение `state.value` во время композиции создаёт зависимость.
  `state:peek()` читает без подписки и удобно в обработчиках событий.
- `state.value = value`, `state:set(value)` и `state:update(fn)` обновляют состояние.
  Для таблиц создавай новое значение: мутация поля существующей таблицы сама
  по себе не уведомляет подписчиков.
- `state:patch(changes)` поверхностно копирует таблицу и заменяет несколько полей.
  `state:update_field(key, value_or_fn)` меняет одно поле; функция получает старое
  значение, вызывается один раз и возвращает новое. `nil` удаляет поле.
- `K.copy(source, changes?)` создаёт обычную поверхностную копию таблицы без
  переноса метатаблицы. Для вложенного обновления используй
  `player:update_field("stats", function(stats) return K.copy(stats, {health = 90}) end)`.
  Deep merge отсутствует. Функцию как значение записывай через patch.
  `patch({field = nil})` не удаляет поле: такая запись не хранится в Lua-таблице.
- `K.remember(init, ...)` сохраняет объект между композициями; дополнительные
  аргументы являются ключами пересоздания. Функция `init` вычисляется при создании.
- `K.form(initial)` запоминает таблицу отдельных State для фиксированной схемы
  формы: `UI.TextField({state = form.name})`. Начальные значения применяются
  один раз; новая схема или полный сброс требуют новой области `K.key`.
  Таблицу полей формы не изменяй, обновляй значения её State.
- Хуки занимают слоты по порядку вызова. Не меняй их количество/порядок
  условными ветками или переменным числом элементов в одной области.
  Выделяй изменяемые ветки и элементы в `K.key` или `K.component`.
- `K.key(id, fn)` связывает дочернюю область с устойчивым ключом. Для списка
  с перестановками используй ID предмета, а не его текущий индекс. Ключи соседей
  должны быть уникальными. Смена ключа создаёт новое состояние и запускает cleanup старого.
- `K.component(fn)` создавай на уровне модуля или через `K.remember`, чтобы
  сохранять идентичность функции компонента.
- Удалённый из композиции компонент теряет локальное состояние. Чтобы сохранять
  данные закрытой вкладки, подними состояние в родителя или внешнюю модель.
- `K.poll(getter, eq?)` нужен для внешних данных, которые сами не реактивны.
  `getter` должен быть дешёвым и без побочных действий.
- Runtime проверяет вид и количество хуков по последней успешной композиции.
  Ошибка `Hook order changed` содержит ожидаемый и фактический хук.
  Подробные Previous/Current и места вызова включаются через
  `K.mount({content = Screen, hook_diagnostics = true})`; в превью они включены
  по умолчанию. Смена двух одинаковых видов хуков может остаться незамеченной.

```lua
local Counter = K.component(function(props)
    UI.Button({
        text = tostring(props.count.value),
        on_click = function()
            props.count:update(function(n) return n + 1 end)
        end,
    })
end)

local Screen = K.component(function()
    local count = K.state(0) -- владелец — экран, а не кнопка
    Counter({count = count})
end)
```

### Эффекты

`K.effect(fn, ...)` выполняет действие после применения кадра; дополнительные
аргументы — значения ключей. Без ключей эффект запускается один раз на жизнь
компонента. Возвращённая функция освобождения вызывается перед повторным
запуском и при удалении компонента. Это не автоматический аналог подписки
на все прочитанные `State`: нужные ключи передавай явно.

`K.on_dispose(fn)` освобождает ресурсы при уходе компонента.
`K.on_frame(fn)` подписывает компонент на кадры; `dt` — секунды.
Callbacks не должны строить дерево или вызывать хуки. Они меняют существующее
состояние, после чего Kompot обновляет композицию.

### Анимации

- `K.animate(target, spec)` возвращает текущее значение, а не State и не объект
  с методами. Поддерживаются числа и массивы чисел, включая цвета из `K.hex`.
- `K.tween(seconds, easing)` задаёт переход по времени.
  `K.spring(stiffness, damping)` — пружину; damping — доля критического затухания.
- `K.snap` — готовая таблица спецификации, её передают без `()`.
- При первом появлении animate сразу принимает начальную цель. Для анимации
  появления сначала задай начальное значение, затем измени цель таймером или событием.
- Новая цель продолжает переход из текущего положения. Спецификация применяется
  при смене цели; замена одной спецификации при прежней цели не перезапускает tween.
- Shape-дескриптор и hex-строка не являются значениями для `K.animate`.
  Анимируй числовой радиус и затем создавай `K.Shape.rounded(radius)`;
  для цвета сначала вызови `K.hex(...)`.
- `K.clock()` — время жизни области, в секундах; активные часы обновляются каждый кадр.
  `K.after(seconds, key?)` возвращает boolean после задержки. Смена key перезапускает таймер.
- Последовательности, каскады, циклы и ключевые кадры собираются из этих функций.
  Не используй выдуманные `AnimatedVisibility`, `rememberCoroutineScope` или `animateFloatAsState`.
- Для анимации исчезновения держи компонент в дереве до конца перехода;
  немедленное удаление через `if` отменяет его локальные анимации.
- Стабильный ключ сохраняет анимацию при перестановке. Новый ключ перезапускает область.

```lua
local Card = K.component(function()
    local open = K.state(false)
    UI.Button({text = "Переключить", on_click = function()
        open.value = not open:peek()
    end})
    local width = K.animate(open.value and 320 or 180, K.spring(260, 0.8))
    local color = K.animate(K.hex(open.value and "#83CDB5" or "#8EB9EF"), K.tween(0.3))
    K.Box({modifier = M:width(width):height(80):background(color, K.Shape.rounded(12))})
end)
```

### Границы возможностей

- Shape: rectangle, circle, rounded, cut; физические углы top_left/top_right/
  bottom_right/bottom_left; px и проценты меньшей стороны. GenericShape,
  PolygonShape и MorphPolygonShape в этом API отсутствуют.
- `background(shape)` рисует фон. Чтобы обрезать картинки и детей, нужен `clip(shape)`.
  `focus_shape` задаёт форму фокусной рамки в опциях clickable/focusable.
- Нативные текстовые поля внутри повёрнутого/масштабированного слоя или фигурной
  маски не поддерживаются. Полю можно задать фигурный фон и рамку, оставив прямой clip.
- Для editor_state/presentation нужна версия VoxelCore с selection/textLayout/
  externalRendering. Нативное редактирование и каретку проверяй в игре.
- Растровые слои ограничены 2048×2048. Обновление содержимого слоя в движке
  может занимать несколько кадров.
- Для большого списка используй LazyColumn/LazyRow/LazyGrid и стабильные key_of.
- Lua-поля используют Mono из темы. `font = false` явно выбирает резервный normal.

### Первый экран с Kompot UI

Этот пример открывает окно по клавише **H**. В окне есть счётчик: по нему
легко увидеть, что состояние меняет надпись без ручной перерисовки.

Распакуйте релиз Kompot так, чтобы файл `package.json` оказался в
`content/kompot/`. Затем создайте рядом папку `hello`:

```text
content/
  kompot/
  hello/
    package.json
    config/bindings.toml
    scripts/hud.lua
    layouts/hello.xml
    layouts/hello.xml.lua
```

В `hello/package.json` объявите зависимость:

```json
{
  "id": "hello",
  "title": "Hello Kompot",
  "version": "0.1.0",
  "creator": "Your name",
  "dependencies": ["kompot"]
}
```

Клавиша задаётся в `hello/config/bindings.toml`:

```toml
[hello]
open = "key:h"
```

В `hello/scripts/hud.lua` откройте и закройте окно по этой клавише:

```lua
function on_hud_open()
    input.add_callback("hello.open", function()
        time.post_runnable(function()
            if hud.is_open("hello:hello") then
                hud.close("hello:hello")
            elseif not hud.is_inventory_open() then
                hud.show_overlay("hello:hello", false)
            end
        end)
        return true
    end, nil, true)
end
```

`hello/layouts/hello.xml` даёт Kompot прозрачный контейнер на весь экран:

```xml
<?xml version="1.0" encoding="utf-8"?>
<container
    id="root"
    color="#00000000"
    position-func="0,0"
    size-func="unpack(gui.get_viewport())"
/>
```

Интерфейс находится в `hello/layouts/hello.xml.lua`:

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"
local handle

local Screen = K.component(function()
    local count = K.state(0)

    UI.Panel({ title = "Первый экран" }, function()
        K.Text("Нажатий: " .. count.value)
        UI.Button({
            text = "Нажать",
            on_click = function()
                count.value = count:peek() + 1
            end,
        })
    end)
end)

function on_open()
    handle = K.mount({
        target = document.root,
        theme = UI.theme(),
        content = Screen,
    })
end

function on_close()
    if handle then
        handle:dispose()
        handle = nil
    end
end
```

Включите оба пака в мире и нажмите **H**. `K.state` хранит счётчик, а чтение
`count.value` подписывает экран на его изменения. `on_close` освобождает
интерфейс при закрытии окна. Из обработчика внутри окна вызывайте `hud.close`
через `time.post_runnable`, чтобы движок не удалял дерево во время обхода.

Дальше можно открыть [компоненты Kompot UI](#reference-ui) или посмотреть живые
примеры по **F12**. Для своего оформления есть [руководство по дизайн-системам](#reference-design-system).

#### Если окно не открылось

- Проверьте, что мир загружает оба пака и в `hello/package.json` указана
  зависимость `kompot`.
- Имена должны совпадать: `hello.open` для клавиши и `hello:hello` для
  `layouts/hello.xml`. Lua-код окна лежит рядом в `hello.xml.lua`.
- Если окно открылось пустым, проверьте `id="root"` в XML и
  `target = document.root` в `K.mount`.

### Kompot UI

Фирменная дизайн-система Kompot. Она поставляется **внутри
пака `kompot`** и подключается как `require "kompot:ui"`.
Ядро `kompot:kompot` от неё не зависит. Другую систему можно реализовать самому
или установить отдельным паком.

Для игрового оформления достаточно одного пака `kompot`.

- [Полный пример первого мода](#reference-quickstart).

#### Общая форма Shape

С версии 1.1.0 `K.Shape` задаёт общую форму для `background`, `border`,
`shadow`, `clip` и `focus_shape`. Форма не зависит от конкретного размера
элемента: размеры её углов разрешаются после раскладки.

| Конструктор | Результат |
|---|---|
| `K.Shape.rectangle()` | Прямоугольник с прямыми углами |
| `K.Shape.circle()` | Круг для квадрата, капсула для прямоугольника |
| `K.Shape.rounded(size)` | Круглые углы; один размер или таблица четырёх углов |
| `K.Shape.cut(size)` | Прямые срезы; размер измеряется вдоль прилегающих сторон |
| `K.Shape.px(value)` | Размер в пикселях; обычное число означает то же самое |
| `K.Shape.percent(value)` | От 0 до 100 процентов меньшей стороны элемента |

```lua
local S = K.Shape
local shape = S.cut({
    top_left = S.percent(50),
    top_right = S.px(8),
    bottom_right = 0,
    bottom_left = 16,
})

K.Box({modifier = K.M:size(240, 120)
    :shadow(8, shape)
    :background("#386F94", shape)
    :border(2, "#FFFFFF", shape)
    :clip(shape)
    :padding(12)
}, function()
    K.Text("Общая форма")
end)
```

Для одинаковых углов используйте `S.rounded(12)` или
`S.rounded(S.percent(25))`. Таблица принимает физические `top_left`,
`top_right`, `bottom_right`, `bottom_left`; незаданные углы равны нулю.
В одной форме можно смешивать пиксели и проценты, в том числе дробные.
Один дескриптор можно использовать у элементов разных размеров: например,
25% у элемента 200×80 даст 20 px, а у 200×40 - 10 px. Суммы соседних
углов ограничиваются длиной стороны с пропорциональным уменьшением всех
четырёх значений.

Модификатор сохраняет копию формы. Для изменения через состояние создайте
новую форму и передайте её при следующей композиции. Перемещение или смена
цвета не меняет текстуру геометрии; изменение формы или размеров обновляет её.
У `clickable` и `focusable` опция `focus_shape` задаёт форму рамки фокуса.
Старое имя `focus_radius` также принимает форму; при указании обоих
используется `focus_shape`.

Фон рисует форму, рамка обводит её изнутри, тень повторяет силуэт, а `clip`
обрезает последующее содержимое и области ввода. Для срезанных углов толщина
рамки измеряется перпендикулярно диагональному краю. Прямоугольный `clip`
сохраняет быстрый путь без растровой маски; остальные формы используют слой
с теми же ограничениями, что описаны ниже для скруглений. Нативное поле ввода
можно оформить любой формой фона и рамки, но помещать внутрь фигурного `clip`
пока нельзя. Произвольные контуры, логические `start/end` и морфинг в этот API
не входят.

#### Скругление отдельных углов

`background`, `border`, `shadow`, `clip` и `focus_radius` принимают число
для всех углов или таблицу с радиусами в пикселях:

```lua
local corners = K.rounded_corners({
    top_left = 24,
    top_right = 8,
    bottom_right = 0,
    bottom_left = 16,
})

K.Box({
    modifier = K.M:size(240, 120)
        :shadow(8, corners)
        :background("#386F94", corners)
        :border(2, "#FFFFFF", corners)
        :clip(corners)
        :padding(12),
}, function()
    K.Text("Каждый угол отдельно")
end)
```

Таблицу можно передать напрямую; `K.rounded_corners` проверяет и копирует её
для повторного использования. Незаданные углы имеют радиус `0`. Имена задают
физические углы, независимо от направления текста. Радиусы неотрицательные;
если сумма соседних радиусов больше стороны, все четыре уменьшаются
пропорционально. `math.huge` означает половину меньшей стороны; старые
вызовы `background(color, 12)` и `clip()` сохраняют своё поведение.

Фон рисует только свою форму. `clip(corners)` обрезает последующие модификаторы,
картинки и дочерние элементы, включая области ввода. Поэтому тень и рамку
обычно задают перед `clip`, а внутренний отступ - после него. Для картинки
или текстурного фона используйте `clip(corners):background_image(material)`.
`fit = "cover"` у картинки управляет масштабированием, а `clip` - формой обрезки.

В VoxelCore скруглённый `clip` использует растровый слой с прозрачной маской.
Вложенные маски и преобразования поддерживаются; обновление содержимого
проходит через GPU-кадр и может появиться с задержкой в несколько кадров.
Размер исходного и результирующего слоя ограничен 2048 пикселями по каждой
оси, как у `rotate`/`scale`.
Нативные `TextInput`/`BasicTextField` внутри скруглённого `clip` пока не поддерживаются:
задавайте полю скруглённые фон и рамку, оставляя его обрезку прямоугольной. `clip(0)` использует обычный
контейнер без растрового слоя.

#### Встроенный справочник

В мире с подключённым паком `kompot` нажмите **F12**, чтобы открыть
**справочник Kompot** с живыми примерами.
Клавишу можно переназначить в настройках управления «Kompot / Справочник»
(`kompot.gallery`). Кнопка закрытия находится в правом верхнем углу.

Три самостоятельных раздела:

- **Игровые окна**: сундук, пауза, верстак, HUD, настройки и состояния ячеек.
  Это первый экран галереи; примеры показаны поверх мира. Кнопка «Код»
  открывает описание и Lua-фрагмент.

- **Ядро**: раскладка, модификаторы, состояние, жизненный цикл,
  взаимодействие, графика, текстовый ввод, анимация, прокрутка и интеграция.
  В группе «Анимация» есть последовательности, параллельные переходы,
  каскадное появление, ключевые кадры с перемоткой, циклы, волны, орбиты,
  смена сцен и перетаскивание с пружинным возвратом. Отдельные примеры
  показывают цепочку по завершению переходов и шкалу с паузой и обратным ходом.
- **Компоненты**: компоненты дизайн-системы, типографика, темы и законченные
  примеры настроек игры, инвентаря и HUD.

В разделах ядра и компонентов слева находится сгруппированный список примеров.
Поиск работает по названию, описанию и именам API, включая кириллицу без учёта
регистра. Для каждого раздела запоминаются выбранная страница и запрос.
При ширине окна меньше 900 пикселей список открывается кнопкой «Разделы и поиск».

В «Оформлении» меняются акцент и плотность всей оболочки и примеров.
Настройки можно сбросить. Страницы темизации отдельно показывают создание
и наследование тем через API.

У каждого живого примера собственное состояние и кнопка «Сбросить».
Уход со страницы завершает её жизненный цикл; при возвращении пример
создаётся заново, а позиция прокрутки страницы сохраняется. Закрытие справочника
освобождает компоненты, таймеры и нативные поля ввода.

Отображаемый исходник и живая демонстрация используют один код из каталога.
Полный фрагмент включает импорты, композицию и вызов `K.mount`; его можно
выделить в поле кода и скопировать Ctrl+C. Длинный код прокручивается внутри
поля. Разделы подключения и регистрации превью содержат самостоятельные
скрипты: они не запускаются внутри открытого справочника.

Примеры `editor_state` и `presentation` включаются автоматически, если
бэкенд обнаружил API текстовой раскладки VoxelCore. На прежнем движке
показываются объяснение зависимости и код без попытки создать несовместимое поле.

Открыть справочник из своего инструмента: `require("kompot:ui").open_gallery()`.
Обычный `require "kompot:ui"` не загружает каталог и не создаёт его интерфейс.
Выполнения произвольного Lua-кода в игровом справочнике нет.

##### Устройство каталога

- `modules/ui/gallery.lua`: оболочка, навигация, поиск, оформление.
- `modules/ui/guide.lua`: реестр, поиск, компиляция поставляемых примеров.
- `modules/ui/guide/components.lua`: компоненты и текстовые поля.
- `modules/ui/guide/foundation.lua`: механизмы ядра и темизация.
- `modules/ui/guide/animations.lua`: простые и сложные анимации ядра.
- `modules/ui/guide/recipes.lua`: игровые интерфейсы и интеграция.
- `modules/ui/previews.lua`: превью из того же каталога для редактора.

Новый пример регистрируется через `G.add(group, id, title, description, apis,
source, opts)`. `id` уникален, `apis` участвует в поиске, `source` содержит
самодостаточное тело композиции с доступными `K`, `UI`, `M`. Проверка галереи
компилирует и компонует все примеры отдельно, чтобы они не зависели от
состояния соседних страниц. Пользовательский код этот загрузчик не принимает.

##### Фрагменты Lua в своём интерфейсе

`UI.Lua` и `UI.TextField` используют общее основание `K.BasicTextField`,
но оформляются независимо. VoxelCore рисует многострочный исходник
с нативной подсветкой Lua, выделением и копированием. Поле имеет
`editable = false`: код не редактируется и не выполняется.
Параметры `lines` и `height` ограничивают видимую область длинного фрагмента.

```lua
UI.Lua({
    code = [[local count = K.state(0)
K.Text(count.value)]],
    title = "Состояние",
    line_numbers = true,
    modifier = K.M:fill_max_width(),
})
-- Для короткого фрагмента: UI.Lua("K.Text('Привет')")
```

#### Плотность и поверхности

По умолчанию используется `density = "comfortable"`: кнопки высотой
28/36/44 px, отступ панели 16 px, промежуток 12 px. Для плотных инструментов:

```lua
local theme = UI.theme({density = "compact"})
-- Или только для части экрана:
UI.Theme({density = "compact"}, function()
    UI.Button({text = "Действие"})
end)
```

`compact` сохраняет прежние основные размеры: кнопки 24/26/28 px,
отступ панели 10 px, промежуток 6 px. Скругления и палитра общие.
Галерея использует стандартную плотность; мод выбирает её при создании темы.
Вложенная тема наследует плотность и настройки размеров родителя.
При явной смене плотности размеры сбрасываются к выбранному набору;
`metrics` в том же вызове переопределяет этот набор.

`Panel` по умолчанию имеет фон без полосы. `variant = "flat"` оставляет
заголовок и отступы без фона; `variant = "accent"` добавляет полосу.
`accent` задаёт цвет полосы, но сам по себе её не включает. Для групп внутри одной поверхности используйте
отступы и заголовки, добавляя карточки там, где нужно выделить содержимое.

При смене `accent` цвет `on_primary` автоматически выбирается светлым или
тёмным. Его можно явно задать через `colors`. Существующие интерфейсы
с фиксированными размерами контейнеров следует проверить с новой плотностью
или перевести на `compact`.

#### Быстрый старт

В `package.json` мода добавьте `"dependencies": ["kompot"]`. Ниже показано
содержимое экрана; расположение файлов и открытие окна есть в
[полном примере](#reference-quickstart).

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

local function Screen()
    local enabled = K.state(true)
    local applied = K.state(false)
    UI.Panel({title = "Настройки"}, function()
        UI.Checkbox({checked = enabled.value, label = "Звуки",
            on_change = function(v) enabled.value = v end})
        UI.Button({text = "Применить", variant = "primary",
            on_click = function() applied.value = true end})
        if applied.value then K.Text("Настройки применены") end
    end)
end

local handle = K.mount({theme = UI.theme(), content = Screen})
-- handle:dispose()
```

#### Тема

##### Иконки

Kompot UI поставляет 63 пиксельные иконки в атласе `kompot_ui_icons`.
Они рисуются на сетке 16×16 без сглаживания и тонируются цветом элемента.
`UI.theme()` задаёт этот атлас в `icons`, поэтому внутри темы достаточно
`K.Icon("settings", {size = 20})`. Также доступен явный источник
`K.Icon("kompot_ui_icons:settings")`.

Ядро Kompot содержит только механизм `K.Icon`: без `theme.icons` для короткого
имени нужно передать полное имя `атлас:иконка`. Своя дизайн-система может
указать свой атлас в теме.

##### Скин

Панели, кнопки и углубления используют четыре PNG в
`textures/kompot_ui_skin/`. Для своего оформления достаточно нарисовать PNG
и указать источники в `UI.theme({skin = {panel = "my_skin:panel", ...}})`.
Подробности о размерах, границах и цветных текстурах - в [руководстве по
скинам](SKINS.md).

`UI.theme(opts)` возвращает независимую таблицу настроек. Непереданные
значения берутся из фирменной темы. `UI.current()` возвращает текущую тему
Kompot UI; `UI.DEFAULT` - фирменную. Константы `UI.PALETTE`, `UI.TYPE`,
`UI.METRICS`, `UI.MOTION` описывают исходные значения; менять
оформление следует через тему, а не изменением этих констант.

```lua
local theme = UI.theme({
    name = "my-mod",
    accent = "#E3AF67", -- свой цвет мода
    panel_alpha = 0.96,
    colors = {surface = "#20242B", on_surface = "#F4F4F4"},
    type = {body = {font = "kompot_16", size = 16}},
    metrics = {control = 32, control_lg = 38, pad = 12, gap = 8},
    shapes = {control = 4, panel = 6, card = 4, field = 4},
    motion = {hover = K.tween(0.12)},
    components = {Button = {size = "lg"}, Panel = {spacing = 10}},
})
```

| Настройка | Назначение |
|---|---|
| `colors` | Общие роли `primary`, `on_primary`, `surface`, `on_surface`, `background`, `surface_raised`, `outline`, `error`, `success`, `warning`; подробные роли `action`, `action_hover`, `panel_bg`, `sunken`, `control`, `text`, `muted`, `dim`, `key` и другие |
| `accents` | Необязательные имена цветов, определённые самим модом; встроенных наборов нет |
| `skin` | PNG для `panel`, `button`, `button_pressed`, `inset`; можно заменить отдельные источники |
| `type` | `caption`, `body`, `label`, `strong`, `title`, `heading`, `display`, `mono`; частичное переопределение стилей |
| `metrics` | Размеры контролов, ширина и отступы панелей, промежутки, размеры панелей инструментов |
| `shapes` | Радиус кнопок (`control`), панелей (`panel`), карточек (`card`) и полей (`field`) |
| `motion` | Анимации `hover`, `fast`, `normal` |
| `components` | Значения свойств по умолчанию: `Button = {variant = "primary"}`. Явные свойства компонента имеют приоритет, включая `false` и `0` |
| `ui` | Частичная замена реализаций общего контракта `K.ui()` |

При создании темы общие роли согласуются с подробными: `primary` - с
`accent`, `surface` - с `panel`, `on_surface` - с `text`. Изменение фирменного
акцента также обновляет заливку главного действия; явно указанные `action`
и `action_hover` имеют приоритет. Строковые цвета принимаются в формате hex.

#### Вложенная тема

`UI.Theme(overrides, content)` наследует **текущую** тему Kompot UI и меняет
её только внутри `content`. После выхода восстанавливаются настройки
родителя. Компоненты читают шрифты, цвета и анимации из текущей темы.

```lua
UI.Theme({accent = "#E3AF67", components = {Button = {size = "lg"}}}, function()
    UI.Button({text = "Крупная кнопка", variant = "primary"})
    UI.Button({text = "Маленькая", size = "sm"}) -- явное свойство важнее
end)
```

Готовую полную тему можно передать обычному `K.Theme(theme, content)` или
`K.mount({theme = theme, ...})`. Для частичного изменения с пересчётом
зависимых цветов используйте `UI.theme` / `UI.Theme`.

#### Свои компоненты и общий контракт

Специфичные элементы мода строятся поверх Kompot UI и живут **в самом моде**.
Например, экран настроек конкретного приложения принадлежит этому приложению,
а кнопки, поля, списки и окна - Kompot UI.

В компоненты `Button`, `Panel`, `Card`, `Window`, `Dialog` можно передать
функцию собственного содержимого. Для полностью переносимых экранов
используйте `K.ui()` ([контракт](#reference-design-system)). Компоненты контракта
можно заменить для поддерева, сохранив остальные:

```lua
UI.Theme({ui = {
    Button = function(props, content)
        -- Своя реализация или обёртка над UI.Button.
        UI.Button(props, content)
    end,
}}, function()
    K.ui().Button({text = "Своя кнопка"})
    K.ui().Checkbox({checked = true, label = "Стандартный флажок"})
end)
```

`UI.Button` всегда обозначает фирменную реализацию, `K.ui().Button` -
реализацию из текущего контракта. Прямые `UI.TextField`, `UI.Segmented` и
`UI.ListItem` также доступны. У контракта `secondary` соответствует обычной
кнопке; `Segmented` выбирает по индексу, а `Choice` - по значению.

#### Компоненты

| Компонент | Главное |
|---|---|
| `Panel(props, content)` | Фон поверх мира, необязательная полоса-акцент, заголовок, `header` справа. Непрозрачна для указателя (`block_pointer`): щелчок не уходит в мир |
| `SplitPane` | Две области с перетаскиваемым разделителем, ограничениями размеров и управлением стрелками |
| `Window` | Панель поверх всего с кнопкой «Закрыть», по центру; `modal` - с затемнением |
| `Dialog` | Подтверждение: `title`, `text` (разметка md), `confirm`, `dismiss` |
| `Button` | `variant`: `default`, `primary`, `danger`, `ghost`, `toggle` (с `selected` - включённое условие); `size`: `sm`, `md`, `lg`; `icon`, `trailing`, `compact`, `min_width`, `tooltip`, `on_right_click` |
| `IconButton`, `ToolButton` | Квадратная кнопка со значком; кнопка панели инструментов (значок 24, размеры из темы, выбранная обведена) |
| `Checkbox`, `Switch` | Квадратный флажок, плоский переключатель |
| `Choice` | Выбор значения рядом кнопок: `options = {{value, text}}`, `columns` |
| `Stepper` | «Подпись: значение [-] [+]» - числовые настройки |
| `Slider` | Плоская дорожка, прямоугольный бегунок, подпись и значение |
| `Tabs` | Текстовые вкладки с полосой снизу |
| `Field`, `LabeledField`, `VectorField` | Поле ввода (рамка в фокусе, набранный текст не перетирается извне), с подписью, три поля X/Y/Z |
| `Menu`, `MenuItem`, `MenuDivider`, `MenuBar` | Выпадающее меню с сочетаниями клавиш; строка меню с названием и действиями |
| `Bar`, `key_chips(list)` | Строка подсказок или состояния (разметка md); подсказки клавиш: `{{"ЛКМ", "рисовать"}}` |
| `Toast` | Уведомление с иконкой; `tone = "neutral" / "info" / "success" / "warning" / "error"` |
| `Tooltip` | Подсказка как у элементов движка |
| `ListRow` | Строка списка с кнопкой × |
| `Slot`, `Card`, `Preview` | Ячейка с картинкой (блоки, предметы, число в углу), тёмная карточка, картинка на подложке |
| `TextField`, `Segmented`, `ListItem`, `Section`, `Hint`, `Divider`, `Key`, `Badge`, `ProgressBar`, `Scrollbar` | Мелочи |

Порядок всплывающих слоёв: уведомление −1, окна 0, диалог 10, меню 20,
подсказки 30.

Компонент Kompot UI в чужой теме использует фирменную тему по умолчанию.

##### Уведомления и диалоги

Окна и диалоги по умолчанию без полосы. `variant = "accent"` включает её,
`accent` задаёт цвет. Эти свойства
проходят через `Window` и `Dialog` к `Panel`. `Dialog.icon` задаёт иконку заголовка.

```lua
UI.Toast({text = "Настройки сохранены", tone = "success"})
UI.Toast({text = "Не удалось сохранить", tone = "error"})
UI.Toast({text = "Обычное уведомление"})
```

`Toast` использует цвета темы, её плотность и пиксельную поверхность. По умолчанию
показывает нейтральную иконку; смысловые варианты добавляют цветную иконку
и лёгкую тонировку фона. `icon` заменяет иконку, `icon = false` скрывает её.
`accent` меняет цвет иконки, а полоса появляется только при `variant = "accent"`.
Общие значения можно задать через `UI.theme({components = {Toast = {...}}})`.
Время показа контролирует вызывающий код: пустой `text` скрывает уведомление.

##### Палитра мода

Стандартная палитра Kompot UI - матовые серо-оливковые поверхности.
Основной цвет дают предметы и состояния игры.
Цвет подсказок клавиш независим от `warning`: предупреждения не используются
для обычных сочетаний клавиш. Выбранные и включённые элементы используют
одну акцентную семью цветов.

Собственную палитру храните в моде и передавайте в `UI.theme({colors = ...})`.
Например, Contour хранит прежнюю сине-серую палитру в `contour:ui` и использует
`density = "compact"`. Сам Kompot от Contour не зависит.

#### Раздвижные панели

`SplitPane` делит ограниченную по ширине и высоте область на две панели.
`first` и `second` - функции содержимого. По умолчанию панели расположены
слева направо; `orientation = "vertical"` размещает их сверху вниз.

```lua
local width = K.state(240)
UI.SplitPane({modifier = K.M:fill_max_width():height(400),
    size = width.value, min_first = 160, max_first = 400, min_second = 200,
    on_change = function(value) width.value = value end,
    first = function() K.Text("Навигация") end,
    second = function() K.Text("Редактор") end,
})
```

- `size` - размер первой панели в пикселях без разделителя. Вместе с
  `on_change(value)` позволяет хранить размер снаружи компонента.
- Без `size` компонент хранит размер сам; `default_size` задаёт начальное
  значение (240). `on_change` также можно использовать в этом режиме.
- `min_first` и `min_second` (0) ограничивают обе панели, `max_first` - первую.
  При конфликте минимальный размер имеет приоритет над `max_first`.
  Если места меньше суммы минимумов, они уменьшаются пропорционально.
  Изменение доступного места не перезаписывает выбранный размер.
- `divider_size` (12) задаёт ширину области захвата; `divider_modifier`
  позволяет добавить, например, `tag`. Содержимое панелей обрезается по их границам.
- `enabled = false` запрещает изменение размера пользователем.
- После фокусировки разделителя стрелки вдоль оси меняют размер на `step`
  пикселей (10). Перетаскивание продолжается за пределами разделителя.

В галерее Kompot разделитель меняет ширину навигации. Размер сохраняется в течение
сеанса справочника, включая переходы между страницами и узкую раскладку.

#### Перемещение и изменение размеров окон

У `Window` есть две независимые возможности, выключенные по умолчанию:
`draggable = true` включает перемещение за заголовок, `resizable = true` -
изменение размеров за четыре края и четыре угла. Кнопки заголовка сохраняют
своё действие. Курсор показывает направление изменения размера.

```lua
local bounds = K.state(nil)
UI.Window({title = "Редактор", draggable = true, resizable = true,
    width = 520, height = 320, min_width = 300, min_height = 180,
    max_width = 900, max_height = 700,
    bounds = bounds.value,
    on_bounds_change = function(value) bounds.value = value end,
}, function()
    K.Column({modifier = K.M:fill_max_size()}, function()
        K.Text("Рабочая область")
    end)
end)
```

- `width`, `height` задают исходные размеры; без `height` высота зависит от
  содержимого до первого перемещения или изменения размера.
- `min_width`, `min_height` (200 и 100) и необязательные `max_width`, `max_height`
  ограничивают размеры при `resizable`. Минимум имеет приоритет над максимумом.
  Фактический размер также ограничен доступным экраном.
- `bounds = {x, y, width, height}` задаёт управляемую геометрию в координатах
  хоста Kompot. `on_bounds_change(bounds)` вызывается при перетаскивании.
  Без `bounds` геометрия хранится внутри компонента; callback можно использовать
  и в этом режиме. Для сохранения после удаления компонента храните `bounds` снаружи.
- До первого перемещения действует `placement`. После него положение ограничивается
  границами хоста; уменьшение экрана не оставляет заголовок за его пределами.
- Содержимое изменяемого окна получает доступную область под заголовком и
  обрезается по её границам. Используйте `fill_max_size`, `weight`, прокрутку
  или `SplitPane`, чтобы оно приспосабливалось к размерам.
- `modifier` применяется к окну, `title_modifier` - к области заголовка без кнопок.
  `z` по-прежнему задаёт порядок окон; перемещение не меняет его автоматически.

Для собственного оформления `Panel` также принимает `title_modifier`,
`content_modifier` (обёртка содержимого) и `fill_height` (заполнение заданной высоты).

`M:block_pointer()` блокирует также нативные поля VoxelCore под областью:
они не получают наведение, выделение и щелчки сквозь неё. Это действует и для
немодальных окон; неперекрытая часть фонового интерфейса остаётся доступной.
Пример «Перемещение и размер окон» в справочнике создаёт новый редактор при каждом
нажатии кнопки, с независимыми текстом и геометрией.

### Состояние и обновление таблиц

`K.state(initial)` хранит значение в компоненте. `K.new_state(initial)` создаёт
состояние вне композиции, например для модели окна. Чтение `.value` во время
композиции подписывает компонент на изменения; `:peek()` читает без подписки.

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

local Screen = K.component(function()
    local player = K.state({ name = "Петя", health = 100, coins = 0 })
    K.Column({ spacing = 8 }, function()
        K.Text(player.value.name .. ": " .. player.value.health)
        UI.Button({
            text = "Получить урон",
            on_click = function()
                player:update_field("health", function(health)
                    return math.max(0, health - 10)
                end)
            end,
        })
    end)
end)

K.preview("Игрок", { width = 360, height = 180, theme = UI.theme() }, Screen)
```

#### Замена значения

`state.value = value` и `state:set(value)` заменяют всё значение.
`state:update(fn)` вычисляет новое значение из предыдущего и передаёт его в `set`.

Изменение поля существующей таблицы не уведомляет UI:

```lua
local old = player:peek()
old.health = 90
player.value = old -- ссылка прежняя, уведомления не будет
```

Для таблиц используйте новые значения или методы ниже. Все они работают
через `State:set`, сохраняя обычную подписку и пользовательскую функцию сравнения.

#### Несколько полей: patch

```lua
player:patch({ health = 90, level = 5 })
```

Метод создаёт новую поверхностную копию и заменяет перечисленные поля.
Остальные поля сохраняются. Исходная таблица и таблица изменений не изменяются.
Функции в patch сохраняются как значения и не вызываются.

`patch` работает только со State, содержащим таблицу; аргумент тоже должен
быть таблицей. При неверном типе возникает понятная ошибка.

#### Одно поле: update_field

```lua
player:update_field("health", 90)
player:update_field("coins", function(coins)
    return coins + 100
end)
```

Второй аргумент - новое значение либо функция от предыдущего значения поля.
Функция вызывается один раз. Для отсутствующего поля она получает `nil`.
Вычисляющая функция должна возвращать новое значение, не изменяя старую таблицу.
Если она завершится ошибкой, метод не присвоит новое значение в State.

Метод создаёт новую таблицу и уведомляет подписчиков через `set`.
Ключ может быть любым допустимым ключом Lua, включая числовой индекс массива.
`nil` и NaN в качестве ключа запрещены. State должен содержать таблицу.

Удаление поля:

```lua
player:update_field("temporary", nil)
player:update_field("temporary", function() return nil end)
```

Записать функцию как значение поля можно через `patch`:

```lua
player:patch({ on_damage = callback })
```

В `update_field` функция всегда означает вычисление нового значения.

#### Обычные таблицы: K.copy

```lua
local next_player = K.copy(old_player, { health = 90 })
local duplicate = K.copy(old_player)
```

Первый аргумент должен быть таблицей. Второй - необязательная таблица замен.
Результат всегда новая обычная таблица; метатаблица исходника не переносится.
Массивные элементы, именованные поля и значения `false` копируются как обычно.
Изменения могут добавлять поля или заменять существующие.

#### Вложенные таблицы

Копирование **поверхностное**: вложенные значения сохраняют ссылки.
Переданная вложенная таблица заменяется целиком; глубокого слияния нет.

```lua
-- armor не сохранится: stats заменяется целиком.
player:patch({ stats = { health = 90 } })

-- Изменяется health, armor и другие поля stats сохраняются.
player:update_field("stats", function(stats)
    return K.copy(stats, { health = 90 })
end)
```

Для нескольких вложенных обновлений:

```lua
player:update(function(old)
    return K.copy(old, {
        name = "Петя",
        stats = K.copy(old.stats, { health = 90 }),
    })
end)
```

Это явные изменения: `patch` не интерпретирует строки вроде `"stats.health"`
как пути и не угадывает правила объединения массивов.

`patch({ field = nil })` и `K.copy(old, { field = nil })` не удаляют поле:
Lua не сохраняет такую запись в таблице изменений. Для удаления используйте
`update_field(key, nil)` или удалите поле у новой копии внутри `update`.

Даже пустой patch и присваивание прежнего значения поля создают новую таблицу.
По умолчанию State сравнивает значения через `==`; для обычных таблиц новая
ссылка означает изменение. Дополнительного глубокого сравнения нет.
Если State создан с пользовательским `eq`, он может подавить замену и уведомление.

#### Форма: K.form

Для фиксированного набора независимых полей используйте `K.form(initial)`:

```lua
local Settings = K.component(function()
    local form = K.form({ name = "", enabled = true, size = 10 })
    UI.TextField({ state = form.name, label = "Имя" })
    UI.Switch({
        text = "Включено",
        checked = form.enabled.value,
        on_change = function(value) form.enabled.value = value end,
    })
    UI.Slider({
        label = "Размер", min = 1, max = 20, value = form.size.value,
        on_change = function(value) form.size.value = value end,
    })
end)
```

Результат - запомненная таблица отдельных State: `form.name`, `form.enabled`,
`form.size`. Каждый потребитель подписывается на свои поля. Вызов `K.form`
сам по себе не подписывает владельца на значения всех полей.

Начальные значения применяются только при создании. Новая таблица `initial`
при следующей композиции не сбрасывает введённые данные. Функция в поле
является обычным значением, а не инициализатором. Вложенная таблица является
значением одного State; глубоких реактивных прокси нет.

Набор ключей должен оставаться неизменным в течение жизни формы. Попытка
добавить или убрать поле приводит к ошибке `K.form schema changed`.
Для другой схемы или полного сброса создайте новую область с другим ключом:

```lua
local generation = K.state(0)
UI.Button({text = "Сбросить", on_click = function()
    generation.value = generation:peek() + 1
end})
K.key(generation.value, function()
    local form = K.form({ name = "", enabled = true })
    UI.TextField({ state = form.name })
end)
```

Сама таблица полей предназначена для чтения; не добавляйте и не заменяйте
её State вручную. Меняйте их `.value` или используйте методы State.
Автоматические валидация, reset, submit и dirty-флаги в этот API не входят.

#### Время жизни и диагностика хуков

Хуки `state`, `remember`, `effect` и анимации должны сохранять порядок вызовов
в своей области композиции. Для переменного списка и условных дочерних областей
используйте устойчивые `K.key` или `K.component`.

Если компонент удалён, его локальное состояние удаляется вместе с ним.
Чтобы закрытая вкладка сохраняла данные, храните состояние в родителе или
внешней модели. `patch` и `update_field` не меняют эти правила времени жизни.

С версии 1.2.0 runtime проверяет вид и количество хуков в каждой области.
Базой является последняя успешная композиция. Подмена `state` на `remember`,
добавление или удаление хука в той же области вызывает ошибку
`Hook order changed in component ...` с указанием слота и ожидаемого вида.
Анимации, формы, состояния прокрутки и другие публичные хуки различаются
по своим именам; внутренний `remember` не создаёт ложного несовпадения.

```lua
-- Ошибка: число хуков в одной области зависит от visible.
if visible.value then
    local count = K.state(0)
end

-- Правильно: условное содержимое имеет отдельную область.
if visible.value then
    K.key("counter", function()
        local count = K.state(0)
        K.Text(tostring(count.value))
    end)
end
```

Проверка типов и количества включена всегда. Подробные места вызова и списки
`Previous`/`Current` включаются отдельно:

```lua
K.mount({ content = Screen, theme = UI.theme(), hook_diagnostics = true })
```

Тот же параметр принимает `K.App.new`. В превью диагностика мест вызова
включена по умолчанию; `K.preview(..., {hook_diagnostics = false}, ...)`
отключает только сбор подробных мест, сохраняя защиту слотов.

Проверка сравнивает виды и количество, а не смысл всех вызовов: перестановка
двух `K.state` с тем же количеством слотов может остаться незамеченной.
Стабильные ключи и порядок вызовов всё равно обязательны.
Не вызывайте хуки внутри инициализаторов `remember`/`state`: инициализатор
выполняется только при создании, а хуки должны повторяться при композиции.

Эффекты не запускаются для области, композиция которой завершилась ошибкой.
Вновь созданные в неуспешной попытке слоты освобождаются; предыдущие
успешные State сохраняются. После восстановления правильного порядка
компонент может продолжить работу; для новой структуры используйте новый ключ.

### Преобразования, кадры и перетаскивание

Все возможности ниже доступны в ядре `kompot:kompot`. Примеры есть в разделе
**Base** галереи; их также можно запускать в [превью](#reference-preview).

Фрагменты ниже выполняются внутри `content` для `K.mount` или `K.preview`.
Полный пример подключения есть в [первом экране](#reference-quickstart).

#### Вращение и масштаб

```lua
local K = require "kompot:kompot"
local M = K.M

K.Image("my_pack:head", {
    modifier = M:size(64):rotate(30):scale(1.5)
})
```

`rotate(angle, pivot)` вращает по часовой стрелке, угол задаётся в градусах.
`scale(x, y, pivot)` изменяет масштаб; если `y` пропущен, обе оси получают `x`.
Отрицательный масштаб отражает элемент, нулевой делает его невидимым и
недоступным для указателя.

Точка опоры `pivot` - `{x, y}` в долях размера. По умолчанию это `{0.5, 0.5}`,
центр. `{0, 0}` задаёт левый верх, `{1, 1}` - правый низ. Допустима также
таблица `{x = 0.5, y = 0.5}`.

Преобразуется элемент вместе с содержимым. Размер, занимаемый в раскладке,
сохраняется: соседние элементы не раздвигаются. Для ограничения рисунка
используйте `clip()` у внешнего контейнера.

Порядок модификаторов важен: преобразование действует на следующие слои.

```lua
-- Повернуты фон, текст и область нажатия.
M:rotate(30):background("#386F94"):clickable(on_click)

-- Фон остаётся прямым; повёрнуты следующие слои и содержимое.
M:background("#386F94"):rotate(30):clickable(on_click)
```

Нажатия, наведение и перетаскивание учитывают вложенные преобразования и
обрезку. Область нажатия - преобразованный прямоугольник элемента;
прозрачные пиксели картинки не исключаются из неё.

Угол и масштаб можно анимировать обычным `K.animate`:

```lua
local expanded = K.state(false)
local angle = K.animate(expanded.value and 180 or 0, K.tween(0.6))
K.Image("my_pack:head", {modifier = M:size(64):rotate(angle)})
```

##### Ограничения

Нативный `K.TextInput` внутри преобразованного элемента пока не поддерживается.
Размещайте редактируемые поля вне таких контейнеров.

Размер содержимого преобразованного слоя и его итогового рисунка ограничен
2048 × 2048 пикселями. Большие интерфейсы лучше преобразовывать отдельными
небольшими элементами. При наклонном повороте границы сглаживаются по площади
покрытия пикселя; внутри изображения используется выборка 4 × 4 с учётом alpha.
Это также действует на `Canvas:image`. Цвет прозрачных пикселей не затемняет
края. Повороты на кратные 90° сохраняют прежнюю точную пиксельную выборку.

Одновременное вращение большого числа крупных элементов заметно увеличивает
стоимость кадра. Простое перемещение готового слоя не перерисовывает его текстуру.

В движке изменение содержимого преобразованного контейнера появляется через
несколько кадров; изменение угла уже готового рисунка обновляется сразу.
Для множества небольших движущихся изображений используйте Canvas.

#### Кадровый callback

```lua
local elapsed = K.state(0)
K.on_frame(function(dt)
    elapsed.value = elapsed:peek() + dt
end)
K.Text(string.format("%.1f с", elapsed.value))
```

`dt` - время кадра в секундах. Callback вызывается один раз за кадр, после
обработки ввода и перед окончательной композицией интерфейса. Он работает
даже при отсутствии изменений интерфейса и автоматически отключается при
удалении компонента или закрытии приложения. При повторном появлении
компонент создаёт новую подписку.

Вызывайте `K.on_frame` во время композиции компонента. Внутри callback
обновляйте существующее состояние; создавать компоненты и вызывать хуки там
нельзя. Для чтения текущего состояния удобно использовать `state:peek()`.
Как и другие хуки, подписка должна занимать постоянное место в компоненте;
условно показываемое содержимое оборачивайте в `K.key` или `K.component`.

К примеря для физики используйте фиксированный шаг. Ограничение накопленного времени
защищает симуляцию от большого скачка после паузы:

```lua
local simulation = K.remember(function() return {rest = 0} end)
K.on_frame(function(dt)
    simulation.rest = simulation.rest + math.min(dt, 0.1)
    while simulation.rest >= 1 / 120 do
        simulation.rest = simulation.rest - 1 / 120
        -- Обновить физику на 1/120 секунды.
    end
end)
```

#### Перетаскивание

`on_event(e)` получает фазы `start`, `move`, `end` и `cancel`.
Координаты и смещения учитывают преобразования. В фазе `end` поле
`accepted` сообщает, приняла ли данные цель `drop_target`;
`accepted = false` само по себе не означает отмену.

```lua
local position = K.state({x = 20, y = 20})
local p = position.value
K.Box({modifier = M:offset(p.x, p.y):size(100, 40):draggable({
    on_event = function(e)
        if e.type == "move" then
            local old = position:peek()
            position.value = {
                x = old.x + e.parent_dx,
                y = old.y + e.parent_dy
            }
        elseif e.type == "end" then
            -- e.velocity_x, e.velocity_y: скорость отпускания в px/с.
        elseif e.type == "cancel" then
            -- Остановить перетаскивание; e.reason содержит причину.
        end
    end
})})
```

| Поле события | Значение |
| --- | --- |
| `type` | `start`, `move`, `end` или `cancel` |
| `x`, `y`, `dx`, `dy` | Координаты и смещение в системе элемента |
| `parent_x`, `parent_y` | Координаты в системе содержимого родителя |
| `parent_dx`, `parent_dy` | Смещение в системе родителя, удобно для `offset` |
| `velocity_x`, `velocity_y` | Скорость в системе родителя, пикселей в секунду |
| `button` | `left` или `right` |
| `accepted` | Результат передачи данных цели, при `end` |
| `cancelled`, `reason` | Признак и причина отмены |

После начала перетаскивания указатель захвачен до отпускания кнопки,
даже за пределами элемента и окна Kompot. Escape, удаление элемента,
блокирующий слой или закрытие приложения отменяют захват. Причины отмены:
`escape`, `removed`, `blocked`, `reset`, `cancelled`.

Чтобы передать данные цели `drop_target`, верните их из обработчика в фазе
`start`. Возвращённые значения в остальных фазах игнорируются:

```lua
M:draggable({on_event = function(e)
    if e.type == "start" then
        return {id = "apple", count = 3}
    elseif e.type == "end" then
        -- e.accepted: цель приняла или отклонила предмет.
    elseif e.type == "cancel" then
        -- e.reason: причина отмены.
    end
end})
```

`axis = 1` ограничивает смещения горизонталью, `axis = 2` - вертикалью.
Скорость определяется последним движением; после остановки указателя перед
отпусканием она становится нулевой.

#### Изображения на Canvas

```lua
K.Canvas({width = 200, height = 120, version = angle, draw = function(cv)
    cv:clear(37, 43, 49, 255)
    cv:image("my_pack:head", {
        x = 50, y = 30,
        width = 64, height = 64,
        angle = angle,
        scale = {1.2, 0.8},
        pivot = {0.5, 0.5},
        alpha = 0.75
    })
end})
```

Источник - загруженная текстура, регион атласа или `K.raster`.
`x`, `y` задают левый верх до вращения. Размер по умолчанию равен размеру
источника, угол - `0`, масштаб и прозрачность - `1`.
Также доступны `color` для умножения цвета и `region = {u0, v0, u1, v1}`
для выбора части изображения. Изображения смешиваются с холстом по
прозрачности и обрезаются его границами.

Меняйте `version`, когда рисунок должен обновиться. Без `version` холст
перерисовывается при каждом обновлении его примитива. Для анимации удобно
передавать время или номер кадра. Небольшой `K.raster` создавайте через
`K.remember`, чтобы переиспользовать его во всех сегментах.

### Текстовый ввод

#### Уровни

- `K.TextInput` передаёт параметры нативному textbox VoxelCore.
- `K.BasicTextField` связывает ввод с состоянием, не добавляя рамку, фон или подпись.
- `UI.TextField` добавляет оформление поля и подписи.
- `UI.Lua` использует `BasicTextField` напрямую и добавляет оформление фрагмента кода.

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

local FieldDemo = K.component(function()
    local text = K.state("Привет")
    K.Column({spacing = 8}, function()
        K.BasicTextField({
            state = text,
            modifier = K.M:width(320):height(40),
        })
        UI.TextField({state = text, label = "Тот же текст"})
    end)
end)
```

`state` - обычный Kompot State со строкой. Изменения пользователя записываются
в него перед вызовом необязательного `on_change(text)`. Внешние изменения
применяются и во время фокуса. Нельзя одновременно передавать `state` и `value`.
`state.value` должен быть строкой, `lines` - положительным целым числом.
Пустая строка допустима. В `value` отсутствие значения означает пустую строку.
Размер можно задать через modifier; без явной высоты поле измеряет `lines`
видимых строк и внутренние отступы. `UI.TextField` сохраняет тематическую
высоту однострочного контрола; многострочный измеряется по шрифту.

Для совместимости доступен `value/on_change`: во время фокуса локальный
черновик защищает ввод от повторной передачи старого значения. После потери
фокуса используется внешнее `value`. Если нужно программно менять текст
активного поля, следует использовать `state`. Если изменение отклонено
владельцем, после потери фокуса вернётся прежнее `value`. Смена режима
`editable` или источника `state` очищает локальный черновик.

`editable = false` запрещает изменение пользователем, сохраняя нативное
выделение и копирование. Программные обновления текста остаются доступны.
`on_submit`, `on_focus` и `on_defocus` передаются компоненту-владельцу.

#### Граница нативного бэкенда

Ввод, переносы, hit testing, прокрутка и история редактирования принадлежат
textbox VoxelCore. По умолчанию он также рисует текст и декорации.
`presentation` позволяет Kompot рисовать текст, выделение и каретку по
**раскладке самого textbox**, без повторного вычисления ширин и переносов.
Фон, номера строк и полоса прокрутки остаются нативными.

Обычные поля работают без этих расширений. Для `presentation` и `editor_state`
нужна сборка VoxelCore с API `selection`, `textLayout` и `externalRendering`.
Если этих возможностей нет, бэкенд сообщает об отсутствующем API.
Автоматически заменять их приблизительной отрисовкой он не будет.

Обычный `state` хранит строку. Ни один режим не обещает сохранение
undo-истории при программной замене текста либо пересоздании поля.
При программной замене выделение сбрасывается, позиция курсора ограничивается
новой длиной текста. Обычная перекомпозиция без замены текста сохраняет
курсор, выделение и историю. Начальные отступы и пустые строки сохраняются.

#### Раскладка и обновление параметров

Высота поля зависит от шрифта и числа видимых строк. Для сторонних шрифтов
размер многострочного поля в превью может быть приблизительным - проверяйте
его в игре.

`lines` задаёт высоту видимой области, а не ограничение длины текста.
`height` у оформленных компонентов и `modifier:height()` у BasicTextField
переопределяют её. Длинное содержимое прокручивается нативным textbox.

`wrap` управляет переносом длинных строк в многострочном поле. По умолчанию
перенос включён для обычного текста и выключен при заданной `syntax`.
`UI.Lua` всегда отключает переносы. Если подсветка переключается на лету,
задайте `wrap` явно, чтобы режим переноса оставался прежним.

Изменения текста, обработчиков, цвета, размеров, `hint`, `editable`, `syntax`
и `line_numbers` не пересоздают поле. Изменения шрифта, padding, wrap или
однострочного/многострочного режима требуют пересоздания нативного элемента:
фокус, выделение и undo-история при этом не сохраняются.
Удаление или пересоздание активного поля вызывает `on_defocus` и прекращает
доставку текста прежнему элементу.

Статические превью показывают строки, номера и обрезку, но не нативную
подсветку, взаимодействие, прокрутку или автоматические переносы.
Параметр `presentation`
применяется только в живом интерфейсе VoxelCore: статическое превью его
декорации не воспроизводит.

#### Клавиши нативного поля

| Действие | Поведение |
|---|---|
| Выделение мышью, Ctrl+C | Доступно и при `editable=false` |
| Ctrl+A | Выделяет всё; повторное нажатие снимает выделение |
| Ctrl+V, ввод, Backspace | Изменяют редактируемое поле; заблокированы в режиме только для чтения |
| Ctrl+Z / Ctrl+Y | Нативные undo / redo до программной замены текста |
| Стрелки, Shift+стрелки | Перемещение и выделение в редактируемом поле |
| Enter | Однострочное поле вызывает `on_submit`; многострочное вставляет перевод строки |
| Tab | Текущая интеграция Kompot передаёт фокус навигации, не вставляя отступ и не закрывая HUD |
| Escape в HUD-оверлее | Движок закрывает оверлей целиком |

Стрелки и Shift+стрелки в нативном режиме только для чтения ограничены
движком; гарантируются выделение мышью и Ctrl+A. Поле получает текстовые
клавиши вместо контролов Kompot. Горячие клавиши своего мода следует
отключать через `on_focus` / `on_defocus`: BasicTextField не управляет
произвольными обработчиками других модов. Политика навигации зависит от
интеграции поля в HUD.

#### Состояние редактора и собственная отрисовка

```lua
local editor = K.text_field_state("local answer = 42")
UI.TextField({
    editor_state = editor,
    lines = 4,
    presentation = {
        spans = {{start = 0, finish = 5, color = "#E3AF67"}},
        selection_color = "#386F94AA",
        caret = {shape = "block", color = "#E3AF6770", blink = 0.5},
    },
})
-- Внешняя замена текста и направленного выделения одним обновлением:
editor.value = {text = "Привет", anchor = 6, caret = 0}
```

Вне композиции используйте `K.new_text_field_state(text)`. Начальное
выделение - `{anchor = 0, caret = 0}`. `editor_state`, `state` и `value`
взаимоисключающие. Снимки заменяются целиком; изменять их поля на месте нельзя.
`anchor` - закреплённый конец выделения, `caret` - движущийся конец.
Индексы начинаются с нуля и используют единицы нативного `caret`, а не байты
UTF-8. Концы за пределами текста ограничиваются движком и синхронизируются
обратно. Поддержка графем, IME и дополнительных Unicode-символов на Windows
этим расширением не добавляется; ограничения нативного ввода сохраняются.

Изменение текста записывает новый снимок перед `on_change(text)`.
Перемещения выделения без редактирования считываются каждый кадр и вызывают
`on_selection_change(anchor, caret)`. Внешняя установка состояния этот callback
не вызывает, кроме нормализации индексов движком.

Диапазоны `spans` полуоткрытые: `[start, finish)`. Последний совпавший диапазон
задаёт цвет; шрифт и размеры символов остаются нативными. `presentation`
заменяет нативную подсветку `syntax`: цвета нужно передать через `spans`.
Текст рисуется только для видимых строк, в обрезанной области поля.
`caret.shape` - `"bar"` (по умолчанию) или `"block"`; `width` задаёт ширину
полоски, `blink` - длительность каждой фазы в секундах, `0` отключает мигание.
`editable=false` сохраняет выделение и копирование, скрывая каретку.

Для своей формы каретки задайте callback, возвращающий `rect`/`text` примитивы
в локальных координатах поля:

```lua
presentation = {
    draw_caret = function(r, context)
        return {{kind = "rect", x = r[1], y = r[2] + r[4] - 2,
            w = r[3], h = 2, color = "#60D5FF"}}
    end,
}
```

`r` - `{x, y, ширина_символа, шаг_строки}`; callback вызывается только в
видимой фазе мигания. Этот API отвечает за оформление, не за обработку ввода.
Выключение `presentation` возвращает нативный рендеринг без пересоздания поля.

### Своя дизайн-система для Kompot

Kompot отвечает за состояние, раскладку и ввод. Цвета, шрифты, формы и готовые
компоненты задаёт **дизайн-система**. Вы можете написать свою и распространять
её отдельным паком. Kompot UI уже входит в `kompot`, но ядро не подключает её
само.

Для текстурных панелей и кнопок ядро предоставляет `K.nine_patch`,
`K.raster` и `M:background_image`: [механизм скинов](#reference-skins).

#### Из чего состоит дизайн-система

```
my_ds/
  package.json          {"id": "my_ds", "dependencies": ["kompot"]}
  preload.json          свои шрифты и атласы (необязательно)
  fonts/, textures/     ассеты
  modules/my_ds.lua     публичный модуль: theme(), компоненты
  modules/my_ds/        tokens.lua, components.lua, ui.lua
```

##### 1. Тема

Тема - таблица. Ядро читает из неё только это:

| Поле | Зачем ядру |
|---|---|
| `type[имя] = {font, bold?, size?}` | `Text{style = "имя"}`; `bold` - шрифт для `**жирного**` в разметке md |
| `default_style` | Стиль текста по умолчанию (иначе `"body"`) |
| `colors.on_surface` | Цвет текста и иконок по умолчанию |
| `colors.background` | Фон превью |
| `ui` | Компоненты системы: их возвращает `K.ui()` |
| `icons` | Атлас дизайн-системы для `Icon("имя")`; ядро не задаёт его |
| `fonts` | Дополнительные шрифты для прогрева измерителя (шрифты из `type` прогреваются сами) |

Остальное - ваше: роли цветов, формы, отступы, тени, движение, размеры.
Компоненты читают эти токены через `K.theme()`.

```lua
local K = require "kompot:kompot"

local T = {}

function T.theme(opts)
    local base = {
        name = "pixel",
        colors = {
            background = K.hex("#20161A"),
            surface = K.hex("#3B2A2F"),
            surface_raised = K.hex("#56403F"),
            on_surface = K.hex("#F4E9D8"),
            muted = K.hex("#BFA99A"),
            primary = K.hex("#F2B84B"),
            on_primary = K.hex("#20161A"),
            outline = K.hex("#7A5E54"),
            error = K.hex("#E5533D"),
            success = K.hex("#7DBF5A"),
            warning = K.hex("#F2B84B"),
            wood = K.hex("#8B5A34"),
            wood_dark = K.hex("#5C3A21"),
        },
        type = {
            body = {font = "pixel_16"},
            label = {font = "pixel_16"},
            title = {font = "pixel_24"},
            caption = {font = "pixel_12"},
            heading = {font = "pixel_32"},
            mono = {font = "pixel_16"},
        },
        frame = {texture = "pixel_ui:frame", border = 6},
        ui = T.ui,
    }
    return K.extend_theme(base, opts or {})
end
```

Здесь `pixel_*` обозначает ваши ресурсы шрифтов. Их нужно объявить в
`preload.json`; см. [руководство по шрифтам](#reference-fonts).
Для обычного текста и кода можно взять поставляемое Kompot семейство:
`K.fonts.resolve("kompot:sans", 16)` и
`K.fonts.resolve("kompot:mono", 16)` соответственно.

`K.extend_theme(base, overrides)` делает тему на основе другой (глубокое
слияние, цвета заменяются целиком). Так можно распространять варианты
одной системы.

##### 2. Общие имена (переносимость)

Экран, который обращается только к общим именам, работает в любой системе.

**Роли цветов:** `background`, `surface`, `surface_raised`, `on_surface`,
`muted`, `primary`, `on_primary`, `outline`, `error`, `success`, `warning`.

**Стили текста:** `caption`, `body`, `label`, `title`, `heading`, `display`, `mono`.

Незнакомое имя стиля не ломает экран: `Text` берёт стиль по умолчанию.

##### 3. Компоненты: общий набор `K.ui()`

`theme.ui` - таблица компонентов. Экран получает её через `local UI = K.ui()`
и не знает, какая система включена. Набор и свойства:

| Компонент | Свойства |
|---|---|
| `Button(props, content?)` | `text`, `icon`, `on_click`, `variant` (`primary`, `secondary`, `ghost`, `danger`), `enabled`, `modifier` |
| `IconButton` | `icon`, `on_click`, `selected`, `enabled`, `tooltip` |
| `Checkbox` | `checked`, `on_change(bool)`, `label`, `enabled` |
| `Switch` | `checked`, `on_change(bool)`, `label?` |
| `Slider` | `value`, `min`, `max`, `steps`, `on_change(v)`, `format(v)` |
| `TextField` | `value`, `on_change`, `on_submit`, `label`, `hint`, `supporting`, `error` |
| `Tabs` | `tabs`, `selected` (индекс), `on_select(i)` |
| `Segmented` | `options`, `selected` (индекс), `on_select(i)` |
| `Panel(props, content)` | `title`, `accent?`, `modifier` |
| `ListItem` | `headline`, `supporting`, `icon`, `trailing` (строка или функция), `on_click`, `selected` |
| `Divider` | - |
| `Badge` | `count` |
| `ProgressBar` | `progress` (0..1, `nil` - бегущая) |
| `Tooltip(props, content)` | `text` |
| `Dialog(props, content?)` | `visible`, `on_dismiss`, `title`, `text`, `confirm = {text, on_click, variant}`, `dismiss = {text, on_click}` |
| `Menu(props, content)` | `expanded`, `on_dismiss`, `width` |
| `MenuItem` | `text`, `icon`, `shortcut`, `on_click`, `enabled` |
| `Scrollbar` | `state` (`scroll_state` / `lazy_state`) |

Набор - это минимум для переносимости. Своих компонентов в системе может
быть сколько угодно: `ToolButton` и `Stepper` в Kompot UI, `FAB` и
`NavigationRail`.

Обычно `ui.lua` системы - тонкий слой над её компонентами. Он переводит общие
свойства в свои, например `variant = "secondary"` в нужный стиль кнопки.

##### 4. Публичный модуль

```lua
-- modules/my_ds.lua
local T = require "my_ds:my_ds/tokens"
local C = require "my_ds:my_ds/components"
local UI = require "my_ds:my_ds/ui"

local DS = {tokens = T, ui = UI}
T.ui = UI
function DS.theme(opts)
    return T.theme(opts)
end
for name, fn in pairs(C) do
    DS[name] = fn
end
return DS
```

Подключение в моде:

```lua
local K = require "kompot:kompot"
local DS = require "my_ds:my_ds"

local function MyScreen()
    K.Text("Привет", {style = "body"})
end

local handle
function on_open()
    handle = K.mount({target = document.root, theme = DS.theme(), content = MyScreen})
end

function on_close()
    if handle then
        handle:dispose()
        handle = nil
    end
end
```

#### Как писать компоненты

- **Компонент с хуками - `K.component(fn)`.** Тогда у него своя область:
  его можно вызывать условно, в цикле с `K.key`, и он перестраивается
  отдельно.
- **Модификатор пользователя применяется первым.** Так `modifier = M:padding(8)`
  у кнопки становится внешним отступом:
  `(props.modifier or M):height(26):background(...)`.
- **Токены - из текущей темы.** Если компонент может оказаться в теме другой
  системы, берите запасную тему. Так делают обе готовые системы:
  ```lua
  local function current()
      local t = K.theme()
      return t.my_ds and t or DEFAULT
  end
  ```
- **Состояния наведения и нажатия.** `local inter = K.interaction()`, затем
  `M:clickable(fn, {interaction = inter})` и
  `K.animate(inter.hovered.value and hover or base, tween)`.
  Фон, рамку и прозрачность можно добавлять условно, в том числе перед
  `clickable`: смена оформления сохраняет нажатие, наведение и фокус.
  Если отступы объединяют или разделяют области ввода, нажатие в изменившейся
  области отменяется. Другой обработчик этот клик не получит.
  Сохраняйте порядок модификаторов ввода (`clickable`, `focusable`, `hoverable`
  и других). Для временного отключения `clickable` используйте `enabled = false`.
- **Клавиатура.** Кликабельные элементы с обработчиком `on_click` входят в
  порядок фокуса. Tab и Shift+Tab перемещают фокус, Enter и пробел вызывают
  обработчик, Escape снимает фокус. `inter.focused.value` позволяет менять
  оформление; видимая рамка фокуса появляется автоматически. Параметры
  `focusable = false`, `focus_color` и `focus_radius` у `M:clickable` управляют
  участием в навигации и рамкой. Для элементов без щелчка есть
  `M:focusable(function(key) ... end, {interaction = inter})`; слайдеры Kompot UI
  меняют значение стрелками.
- **Правая кнопка:** `M:clickable(fn, {on_right_click = fn2})`.
- **Необязательные модификаторы перетаскивания:** `M:draggable` и
  `M:drop_target` описывают только события ввода и попадание указателя в цель.
  Логика предметов, окон и других объектов остаётся в приложении.
- **Перетаскивание правой кнопкой:** `M:draggable({button = "right",
  on_event = function(e) if e.type == "start" then return item end end})`.
  Фазы `start`, `move`, `end`, `cancel` и цели `M:drop_target` работают
  так же, как для левой кнопки.
  После перетаскивания `on_right_click` не вызывается.
- **Перетаскивание на цель:** значение, возвращённое из `on_event` в фазе
  `start`, передаётся в
  `M:drop_target({on_enter = function(item) ... end,
  on_leave = function(item) ... end, on_drop = function(item) ... end})`.
  Цель определяется под указателем, даже когда источник удерживает ввод.
  `on_drop` может вернуть `false`, чтобы отклонить перенос. Цель под
  `M:block_pointer()` недоступна. Для игровых экранов добавьте
  `{focusable = false}` к `M:clickable`, если Tab не должен выбирать элементы.
- **Панель поверх мира:** `M:block_pointer()` на фоне панели. Щелчки не
  проходят «сквозь» неё, а `handle:is_over(x, y)` говорит моду, что курсор
  над интерфейсом, а не над миром.
- **Всплывающие слои:** `K.Popup({placement, z}, content)`. Порядок слоёв
  задаёт `z`: в Kompot UI меню - 20, подсказки - 30, диалоги - 10,
  уведомления - −1.
- **Разметка движка** в подписях: `Text(s, {markup = "md"})` понимает
  `[#RRGGBB]` и `**жирный**`, как `label markup="md"`.
- **Подложка точно по содержимому:** `M:match_parent_size()` у ребёнка `Box`.
  Так делаются подчёркивания вкладок, рамки выделения и подсветки.
- **Опрос обычного кода:** `K.poll(getter)` - область перестраивается,
  только когда значение изменилось. Это мост к нереактивному коду мода, как
  `supplier` в XML.

##### Простая сетка инвентаря

`InventoryGrid` показывает переданные предметы, но не меняет их сам.
В обработчике переноса создайте новый список и запишите его в состояние:

```lua
local Inventory = K.component(function()
    local items = K.state({
        [1] = {id = "my_pack:hammer", name = "Молот", src = "my_items:hammer"},
        [2] = {id = "my_pack:stone", name = "Камень", src = "my_items:stone", count = 8},
    })

    V.InventoryGrid({
        items = items.value,
        count = 8,
        columns = 4,
        on_move = function(from, to)
            local next_items = {}
            for index, item in pairs(items:peek()) do
                next_items[index] = item
            end
            next_items[from], next_items[to] = next_items[to], next_items[from]
            items.value = next_items
            return true
        end,
    })
end)
```

`count` нужен даже при пустых ячейках: оператор `#` не определяет нужную
длину списка с пропусками. Чтобы принять или отклонить перенос, `on_move`
возвращает `true` или `false`.

##### Перетаскивание отдельного ItemSlot

Здесь `payload` означает данные переноса: сам предмет или таблицу с ним и
другими нужными модулю сведениями.

- `on_drag_event(e, item)` получает предмет и событие перетаскивания.
  В фазе `start` верните payload; в `move` доступны координаты и смещения;
  в `end` поле `e.accepted` сообщает результат переноса;
  в `cancel` поле `e.reason` объясняет отмену.
- `drag_button="right"` включает перенос правой кнопкой; по умолчанию левая.
- `accepts(payload)` возвращает `false`, если размещение запрещено.
- `on_drop(payload)` принимает перенос; `false` отклоняет его.

```lua
UI.ItemSlot({item = item, on_drag_event = function(e, source_item)
    if e.type == "start" then return source_item end
end})
```

Поля события описаны в [перетаскивании](#reference-motion).

Источник показывает полупрозрачный предмет, а изображение переноса следует
за указателем. Цель получает зелёную или красную рамку. Заблокированные и
недоступные слоты не принимают действия. После завершения переноса
`on_click` не вызывается.

`InventoryGrid` передаёт payload `{index, item, group}`. По умолчанию `group`
уникален для сетки. Для связи сеток можно передать одинаковый `drag_group`,
но обработка источника, индексов и общего хранилища тогда принадлежит моду.
Для инвентарей с разными правилами удобнее отдельные `ItemSlot` и свой payload.

#### Темизация

`V.theme(opts)`, `V.Theme(opts,content)`, `V.current()`, `V.DEFAULT`,
`V.PALETTE`, `V.TYPE`, `V.METRICS`, `V.tokens`, `V.ui`.

Параметры: `name`, `accent`, `density`, `panel_alpha`, `colors`, `type`,
`metrics`, `shapes`, `motion`, `components`, `ui`. Готовых цветовых
пресетов нет; мод задаёт свои цвета через `colors` или `accent`.
`components` задаёт значения по умолчанию по имени компонента;
явные свойства имеют приоритет. Игровые составные компоненты принимают
настройки через собственные props; ItemSlot также читает `components.ItemSlot`.

Особые роли цветов: `edge`, `shadow`, `health`, `energy`, `experience`.
Общие роли: `background`, `surface`, `surface_raised`, `on_surface`, `primary`,
`on_primary`, `outline`, `muted`, `error`, `warning`, `success`.

#### Жизненный цикл

Галерея создаёт mount в `on_open` и освобождает в `on_close`.
Свой экран должен делать то же самое. Закрытие HUD из обработчика клика
откладывайте через `time.post_runnable`, чтобы не удалять дерево во время
обхода движком. Данные игры передавайте через `K.state`, `K.new_state` или
`K.poll`. Библиотека не записывает предметы или настройки в мир самостоятельно.

#### Оформление поверхностей

Окна и контролы используют PNG-скин `textures/kompot_ui_skin/`: грань и зерно
привязаны к пикселям, углы прямые. `radius` не меняет геометрию этого скина.
Цвета и текстовые роли задаются через `V.theme()`. По умолчанию во всех
ролях используется семейство IBM Plex: Sans для обычного текста,
Mono для моноширинных надписей.

### Шрифты

#### Что входит в Kompot

Для обычного текста используются шрифты IBM Plex:

| Шрифт | Имя для `K.Text` |
|---|---|
| Sans - обычный текст | `kompot_<размер>` |
| Sans SemiBold - выделенный текст | `kompot_sb_<размер>` |
| Mono - моноширинные надписи | `kompot_mono_<размер>` |

Доступные размеры: **11, 12, 13, 14, 16, 20, 24, 32, 44**.

```lua
K.Text("Обычный текст", {font = "kompot_16"})
K.Text("Заголовок", {font = "kompot_sb_24"})
K.Text("123 / 456", {font = "kompot_mono_14"})
```

Компоненты выбирают шрифт из темы, поэтому указывать `font` для каждой
надписи необязательно. Для изменения размера выберите ресурс нужного размера,
например `kompot_24`.

`UI.Lua` и поля с `syntax = "lua"` по умолчанию используют стиль `mono`
текущей темы: IBM Plex Mono, 16 px во встроенной теме Kompot UI
(`kompot_mono_16`), 13 px в базовой теме ядра (`kompot_mono_13`).
Переопределение `theme.type.mono` применяется и к Lua-коду. Явный `font`
имеет приоритет; `font = false` оставлен для выбора резервного растрового
шрифта движка `normal`. В актуальном VoxelCore исправлена работа каретки
и выделения с векторным Mono, поэтому обходной выбор `normal` больше не нужен.

#### Как подключить свой шрифт

##### 1. Добавьте файлы в пак

Например, в паке `my_ui`:

```text
my_ui/
  fonts/
    My-Regular.ttf
    My-Semibold.ttf
  modules/
    fonts.lua
  preload.json
```

Подходят TTF и OTF. Проверьте, что лицензия позволяет распространять шрифт
вместе с вашим паком и что он содержит нужные символы.

##### 2. Объявите размеры в `preload.json`

Добавьте записи в массив `fonts`, сохранив остальные настройки файла:

```json
{
  "fonts": [
    {"name": "my_sans_14", "path": "fonts/My-Regular.ttf", "size": 14},
    {"name": "my_sans_sb_14", "path": "fonts/My-Semibold.ttf", "size": 14}
  ]
}
```

`path` задаётся относительно вашего пака. Для каждого используемого размера
нужна отдельная запись.

##### 3. Зарегистрируйте семейство

В `my_ui/modules/fonts.lua`:

```lua
local K = require "kompot:kompot"

K.fonts.register_family("my_ui:sans", {
    {name = "my_sans_14", file = "my_ui/fonts/My-Regular.ttf", size = 14},
    {name = "my_sans_sb_14", file = "my_ui/fonts/My-Semibold.ttf", size = 14, weight = "semibold"},
})
```

Здесь `name` и `size` должны совпадать с `preload.json`, а `file` включает
имя пака. Добавьте записи для остальных размеров, которые объявили.

##### 4. Используйте шрифт

Загрузите модуль регистрации перед созданием интерфейса:

```lua
local K = require "kompot:kompot"
require "my_ui:fonts"

-- Внутри содержимого экрана или превью:
K.Text("Текст", {font = K.fonts.resolve("my_ui:sans", 14)})
K.Text("Выделенный текст", {font = K.fonts.resolve("my_ui:sans", 14, "semibold")})
```

Те же имена шрифтов можно указать в стилях своей [темы](#reference-design-system).
Регистрация позволяет использовать шрифт и в игре, и в [превью](#reference-preview).

#### Шрифт из PNG

Для растрового шрифта подготовьте страницы `pixel_0.png`, `pixel_1.png`
и далее, по 16×16 ячеек на страницу. Например, при размере ячейки 16 пикселей
размер страницы составляет 256×256.

В `preload.json` укажите общий префикс без номера страницы и расширения:

```json
{"fonts": [{"name": "my_pixel", "path": "fonts/pixel"}]}
```

Зарегистрируйте шрифт, указав размер ячейки и `kind = "bitmap"`:

```lua
K.fonts.register_family("my_ui:pixel", {
    {name = "my_pixel", file = "my_ui/fonts/pixel", size = 16, kind = "bitmap"},
})
```

После загрузки этого модуля используйте `K.Text("Текст", {font = "my_pixel"})`.

### Текстурные фоны и скины

`K.nine_patch` описывает материал, `M:background_image` рисует его на любом
контейнере. Фон не влияет на измерение и не перехватывает ввод. Порядок
модификаторов тот же, что у `background`: padding перед фоном задаёт внешний
отступ, после него - внутренний.

```lua
local K = require "kompot:kompot"
local M = K.M

local panel = K.nine_patch("my_ui:panel", {
    source_size = {32, 32},
    border = 4,
    center = "tile",
    edges = "stretch",
    scale = 2,
})

local Panel = K.component(function()
    K.Box({modifier = M:background_image(panel):padding(12)}, function()
        K.Text("Содержимое панели")
    end)
end)
```

Источник - уже загруженная текстура или спрайт атласа, как для `K.Image`.
`source_size` - размер самого спрайта. Координаты и границы источника
отсчитываются от верхнего левого угла.

| Свойство | Значение |
|---|---|
| `border` | Число или `{left, top, right, bottom}` в целых пикселях источника; по умолчанию 0 |
| `center` | `stretch`, `tile` или `none`; по умолчанию `stretch` |
| `edges` | `stretch` или `tile`; по умолчанию `stretch` |
| `scale` | Положительный масштаб углов и повторяемой фактуры; по умолчанию 1 |

Границы оставляют непустую середину исходника. У слишком маленького элемента
толщина краёв уменьшается пропорционально. Последний повтор фактуры обрезается.
`border = 0, center = "tile"` даёт обычный повторяющийся фон без рамки.
Дополнительный аргумент `background_image(panel, "#FFFFFF80")` задаёт tint и
прозрачность; `M:alpha` также применяется к фону.

#### Скин Kompot UI из PNG

Штатный игровой скин лежит в `textures/kompot_ui_skin/`. Это четыре обычных
PNG: `panel.png` (панели) и `inset.png` (углубления и слоты) размером
264×264, `button.png` (кнопки) и `button_pressed.png` (нажатые кнопки)
размером 72×72. Их можно открыть в пиксельном редакторе и заменить в своём
паке. Исходный набор служит образцом: внешний край занимает 4 пикселя, а
верхний край углубления и нажатой кнопки - 6 пикселей. Середина и края
повторяются; углы остаются целыми при любом размере окна.

Зерно повторяется вместе с серединой, поэтому у поверхностей, которые бывают
большими, середина 256×256: при середине 64×64 узор повторялся бы каждые
64 пикселя, и на широком окне это читается как сетка. Если рисуете свой
скин, избегайте того, за что цепляется глаз при повторе: пятен на
регулярной решётке (их прямые края складываются в сетку), сгустков точек и
заметных одиночных деталей. Узор должен бесшовно продолжаться через край
середины.

Положите файлы в `textures/my_pack_skin/`, добавьте атлас в
`preload.json` своего пака, затем укажите источники в теме:

```json
{"atlases": [{"name": "my_pack_skin"}]}
```

```lua
local UI = require "kompot:ui"

local theme = UI.theme({skin = {
    panel = "my_pack_skin:panel",
    button = "my_pack_skin:button",
    button_pressed = "my_pack_skin:button_pressed",
    inset = "my_pack_skin:inset",
}})
```

Для своих файлов, заданных строкой, Kompot UI предполагает размер 72×72.
Файл другого размера задайте записью с `source_size`:
`panel = {src = "my_pack_skin:panel", source_size = {264, 264}}`.

Можно заменить только один файл; остальные придут из Kompot UI. По умолчанию
нейтральные текстуры тонируются цветом компонента. Для готового цветного PNG
отключите тонировку: `panel = {src = "my_pack_skin:panel", tint = false}`.
У такой записи также можно задать `source_size`, `border`, `center`, `edges`
и `scale` как у `K.nine_patch`; `midtone` меняет опорную яркость для тонировки.
Файл и его атлас должны быть доступны движку до первого показа окна.

#### Маленькие процедурные материалы

```lua
local source = K.raster({
    key = "my_pack:stone", -- общая идентичность ресурса
    version = 1,
    width = 32, height = 32,
    draw = function(canvas, w, h)
        canvas:clear(60, 65, 55, 255)
        canvas:rect(0, 0, w, 2, 90, 95, 75, 255)
        canvas:rect(0, h - 2, w, 2, 30, 35, 25, 255)
    end,
})
local material = K.nine_patch(source, {border = 2, center = "tile"})
```

Храните описание вне композиции или в `K.remember`. Без `key` каждый вызов
`K.raster` создаёт новую идентичность. С явным ключом одинаковые описания
разделяют ресурс между компонентами и хостами. Включайте имя пака в ключ.
Для одного ключа и версии callback должен давать одинаковые пиксели.

При изменении пикселей создайте описание с новой `version`. Изменение цвета
через tint, размера окна, позиции или масштаба не запускает callback заново.
Описание не следует изменять на месте. Callback получает **размер источника**,
который не зависит от размера панели.

#### Стоимость и жизненный цикл

- Не больше девяти нативных изображений на фон, в том числе при `tile`.
- Повторение выполняется через UV на GPU. Тысячи плиток не становятся
  тысячами GUI-элементов.
- Части источника выделяются один раз; спрайты атласа изолируются, чтобы
  повторение не захватывало соседние изображения.
- Источник PNG читается при первом использовании; маленький raster вычисляется
  тогда же. Создание большого procedural-источника всё ещё может быть дорогим.
- Ресурсы разделяются между открытыми окнами. Закрытие освобождает ссылки;
  неактивные слоты кэша переиспользуются вместе с именами GPU-текстур.
  Обычный пул содержит до 64 материалов; расширение требуется, только когда
  все слоты одновременно заняты. Память зависит от размеров исходников и
  максимального числа одновременно удерживаемых материалов, а не от размеров
  окон или числа прошлых открытий.
- Смена ассетов сбрасывает кэш и восстанавливает текстуры при использовании.

Kompot UI использует четыре PNG через `K.nine_patch`. Выделение ячейки
остаётся обычной рамкой, поэтому оно не создаёт отдельный материал.

### Превью в VS Code

Расширение **Kompot Lens** позволяет смотреть интерфейс рядом с Lua-кодом,
нажимать кнопки и проверять анимации без запуска игры.

#### Первое превью

1. Установите [Kompot Lens](https://marketplace.visualstudio.com/items?itemName=BooleanFalse.kompot-lens)
2. Откройте в VS Code папку своего пака или проекта. Пак `kompot` должен лежать рядом с вашим паком в каталоге паков.
3. Добавьте `K.preview` в Lua-модуль своего пака, например `modules/previews.lua`:

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

K.preview("Счётчик", {
    width = 360,
    height = 120,
    theme = UI.theme(),
}, function()
    local count = K.state(0)
    UI.Button({
        text = "Нажато: " .. count.value,
        on_click = function()
            count.value = count:peek() + 1
        end,
    })
end)
```

Сохраните файл и выполните **Kompot: Открыть превью** (`Ctrl+K V`, на macOS -
`Cmd+K V`). Нажмите **Интерактивно**, чтобы проверить кнопку.

В одном файле можно объявить несколько превью с разными именами - например,
для обычного и узкого окна. Внутри используйте те же компоненты, состояния
и модификаторы, что и в игровом интерфейсе.

#### Настройки `K.preview`

| Поле | Значение |
|---|---|
| `width`, `height` | Размер области превью; по умолчанию 400×300 |
| `theme` | Тема интерфейса или функция, которая её возвращает; по умолчанию базовая тема Kompot |
| `padding` | Отступ от краёв; по умолчанию 16. Значение `0` убирает отступ |
| `group` | Название группы, например `"Кнопки"` |
| `hook_diagnostics` | Подробные места вызова хуков; по умолчанию `true`. Проверка типов и количества хуков действует всегда |

Укажите ту же тему, которую используете в игре, чтобы совпадали оформление
и шрифты. Для другого размера окна создайте отдельное превью с тем же содержимым.

#### Работа в редакторе

- Сохранение файла обновляет превью. Для обновления при наборе выберите `live`
  в настройке `kompot.previewUpdateMode`.
- Масштаб и кнопка **Вписать** помогают просматривать широкие интерфейсы.
- В интерактивном режиме работают состояния, кнопки и анимации.
- Команда **Kompot: Добавить превью** вставляет шаблон в текущий файл.

Если пак не найден, нажмите **Выбрать каталог паков** в превью. Выбор
сохраняется для проекта. Для подсказок и проверки типов достаточно зависимости
`"kompot"` в `package.json`, даже если сам пак ещё не установлен.

Чтобы использовать свой Lua или LuaJIT, укажите путь в `kompot.luaExecutable`.
Для встроенных текстур и растрового шрифта движка может понадобиться путь
к каталогу `res` в `kompot.enginePath`.

О подключении своих шрифтов - в [руководстве по шрифтам](#reference-fonts).

Нативный текстовый ввод, каретку, выделение и подсветку проверяйте в игре.

#### Формат скруглений для внешних отрисовщиков

В `kompot-preview/1` поле `radius` у `rect`, `border`, `shadow` допускает
число или объект `{top_left, top_right, bottom_right, bottom_left}`. Все
значения уже ограничены размерами фигуры. Старый числовой формат сохраняется.
Скруглённый `clip` представлен примитивом `layer` с `mask_radius` в таком же
формате. Маска применяется один раз к собранному содержимому слоя; вложенные
`prims`, `transform` и `source_bounds` остаются частью обычного формата слоя.
Маску нельзя терять при объединении соседних преобразований.

##### Shape

Новые формы сериализуются в поле `shape` у `rect`, `border`, `shadow` и в
`mask_shape` у `layer`. Контур имеет `kind: "rounded" | "cut"` и четыре
числовых поля `top_left`, `top_right`, `bottom_right`, `bottom_left` в пикселях.
Проценты разрешаются по исходной геометрии элемента до передачи отрисовщику;
размытие тени в размер для расчёта процентов не входит. `circle` разрешается
в `rounded`, а `rectangle` использует прежний прямоугольный примитив.
Поля `radius` и `mask_radius` сохраняются для старых вызовов. Новые
отрисовщики сначала проверяют `shape`/`mask_shape`, затем старые поля.
Идентичность кэша учитывает тип контура: одинаковые размеры rounded и cut
дают разные текстуры. Маска применяется один раз к собранному слою.

## Рецепты из галереи

Это реальные фрагменты встроенного справочника. Каждый фрагмент — отдельный
пример; он выполняется **во время композиции**, а не при загрузке Lua-модуля.
Для запуска используй такую оболочку, вставив один фрагмент вместо комментария:

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"
local M = K.M

local Example = K.component(function()
    K.Column({modifier = M:fill_max_width(), spacing = 12}, function()
        -- Один фрагмент из примеров ниже.
    end)
end)

K.preview("Пример", {width = 640, height = 600, theme = UI.theme()}, Example)
-- В игре: local handle = K.mount({content = Example, theme = UI.theme()})
-- При закрытии: handle:dispose()
```

Все фрагменты используют эти `K`, `UI`, `M`. Одинаковые имена переменных между
примерами не означают общую модель. При объединении примеров сохраняй постоянный
порядок хуков и задавай уникальные ключи.

### Row, Column и Spacer

Одинаковые элементы в строке и колонке. Spacer с weight занимает свободное пространство строки.

```lua
local gap = K.state(8)
UI.Slider({
    label = "Расстояние",
    value = gap.value,
    min = 0,
    max = 32,
    step = 4,
    on_change = function(v)
        gap.value = v
    end,
})
K.Row({ modifier = M:fill_max_width(), spacing = gap.value }, function()
    UI.Key("Слева")
    K.Spacer(M:weight(1))
    UI.Key("Справа")
end)
K.Column({ spacing = gap.value }, function()
    UI.Key("Сверху")
    UI.Key("Снизу")
end)
```

### FlowRow и переносы

Изменяйте ширину области. Элементы переносятся целиком, сохраняя расстояние между строками.

```lua
local width = K.state(280)
UI.Slider({
    label = "Ширина области",
    value = width.value,
    min = 140,
    max = 360,
    step = 10,
    on_change = function(v)
        width.value = v
    end,
})
K.FlowRow({
    modifier = M:width(width.value):background(K.theme().colors.surface_raised):padding(8),
    spacing = 6,
    run_spacing = 6,
}, function()
    for _, name in ipairs({
        "Камень",
        "Дерево",
        "Железо",
        "Золото",
        "Стекло",
        "Земля",
    }) do
        UI.Key(name)
    end
end)
```

### Порядок модификаторов

Сравните фон до padding и после него. Порядок цепочки определяет, какую область занимает оформление.

```lua
K.Text("background -> padding")
K.Box({ modifier = M:background("#386F94"):padding(20) }, function()
    K.Text("Внутренний отступ")
end)
K.Text("padding -> background")
K.Box({ modifier = M:padding(20):background("#386F94") }, function()
    K.Text("Внешний отступ")
end)
```

### Выравнивание и слои

Меняйте положение элемента внутри Box. Второй слой расположен поверх фона.

```lua
local align = K.state("center")
UI.Choice({
    options = { "top_start", "center", "bottom_end" },
    selected = align.value,
    on_select = function(v)
        align.value = v
    end,
})
K.Box(
    {
        modifier = M:fill_max_width():height(140):background(K.theme().colors.surface_raised),
        align = align.value,
    },
    function()
        K.Box({ modifier = M:match_parent_size():border(1, K.theme().colors.outline) })
        UI.Key("Положение: " .. align.value)
        K.Text("Слой 2", { modifier = M:align("top_end"):padding(6):z_index(2) })
    end
)
```

### Размеры и обрезка

Прозрачность меняет всю группу. Текст обрезается по ширине; квадрат сохраняет соотношение сторон.

```lua
local alpha = K.state(1)
UI.Slider({
    label = "Прозрачность",
    value = alpha.value,
    min = 0.2,
    max = 1,
    on_change = function(v)
        alpha.value = v
    end,
})
K.Box({
    modifier = M:width(160)
        :aspect_ratio(1)
        :alpha(alpha.value)
        :shadow(4, 10)
        :background(K.theme().colors.primary, 10)
        :clip()
        :padding(12),
}, function()
    K.Text(
        "Длинный текст внутри ограниченной области",
        { color = "#181818" }
    )
end)
```

### Своя раскладка

Layout измеряет детей и размещает их по диагонали. Подпись показывает итоговый размер после раскладки.

```lua
local size = K.state("Ожидание раскладки")
K.Layout({
    modifier = M:on_size(function(w, h)
        size.value = string.format("Размер: %.0f x %.0f", w, h)
    end),
    measure = function(children, minW, maxW, minH, maxH, api)
        local width, height = 0, 0
        for i, child in ipairs(children) do
            local x, y = (i - 1) * 28, (i - 1) * 32
            local w, h = api.measure(child, 0, math.max(0, maxW - x), 0, maxH)
            api.place(child, x, y)
            width, height = math.max(width, x + w), math.max(height, y + h)
        end
        return width, height
    end,
}, function()
    UI.Key("Первый")
    UI.Key("Второй")
    UI.Key("Третий")
end)
K.Text(size.value)
```

```lua
K.Box({
```

### Перетаскивание

Потяните плашку по горизонтали. Смещение ограничено шириной дорожки.

```lua
local x = K.state(0)
K.Box({ modifier = M:width(300):height(80):background("#25252B"):block_pointer() }, function()
    K.Box({
        modifier = M:offset(x.value, 16):size(80, 48):background("#386F94", 8):draggable({
            axis = 1,
            on_event = function(e)
                if e.type == "move" then
                    x.value = math.max(0, math.min(220, x:peek() + e.parent_dx))
                end
            end,
        }),
        align = "center",
    }, function()
        K.Text("Тяни")
    end)
end)
K.Text(string.format("Смещение: %.0f", x.value))
```

### Цель перетаскивания

Перетащите предмет в ячейку. Цель получает события входа и отпускания.

```lua
local status = K.state("Перетащите предмет")
K.Row({ spacing = 16 }, function()
    K.Box({
        modifier = M:size(100, 64):background("#386F94", 8):draggable({
            on_event = function(e)
                if e.type == "start" then
                    return "Предмет"
                elseif e.type == "cancel" then
                    status.value = "Перенос отменён"
                elseif e.type == "end" and not e.accepted then
                    status.value = "Цель не приняла предмет"
                end
            end,
        }),
        align = "center",
    }, function()
        K.Text("Предмет")
    end)
    K.Box({
        modifier = M:size(140, 64)
            :background("#303036", 8)
            :drop_target({
                on_enter = function()
                    status.value = "Над ячейкой"
                end,
                on_leave = function()
                    status.value = "Вне ячейки"
                end,
                on_drop = function(item)
                    status.value = item .. " перенесён"
                end,
            })
            :block_pointer(),
        align = "center",
    }, function()
        K.Text("Ячейка")
    end)
end)
```

### Ключевые кадры и перемотка

Один ползунок управляет всей сценой: движение вправо, вниз, влево и вверх с изменением размера и цвета.

```lua
local position = K.state(0)
UI.Slider({label = "Позиция на шкале", min = 0, max = 4, value = position.value,
    on_change = function(v) position.value = v end})
local frames = {
    {x = 12, y = 12, size = 36, color = K.hex("#81C9BC")},
    {x = 230, y = 12, size = 52, color = K.hex("#EAC778")},
    {x = 230, y = 100, size = 36, color = K.hex("#CF8BAD")},
    {x = 12, y = 100, size = 52, color = K.hex("#6487BE")},
    {x = 12, y = 12, size = 36, color = K.hex("#81C9BC")},
}
local p = position.value
local index = math.min(4, math.floor(p) + 1)
local t = K.EASING.in_out_cubic(p - (index - 1))
local a, b = frames[index], frames[index + 1]
local function mix(from, to) return from + (to - from) * t end
local color = {}
for i = 1, 4 do color[i] = mix(a.color[i], b.color[i]) end
K.Text(string.format("Кадр %d → %d: %.0f%%", index, index + 1, t * 100))
K.Box({modifier = M:width(300):height(170):background("#252B31"):clip()}, function()
    K.Box({modifier = M:offset(mix(a.x, b.x), mix(a.y, b.y)):size(mix(a.size, b.size)):background(color, 6)})
end)
```

Интерполяция не зависит от времени: её можно использовать для редактора, перемотки повтора или перехода, управляемого жестом.

### Цикл туда и обратно

Треугольная волна задаёт направление, а кривая плавности смягчает разворот. Остановка удаляет часы из композиции.

```lua
local running = K.state(true)

    running.value = not running:peek()
end})
local function draw(t)
    local phase = (t / 1.2) % 2
    local progress = phase <= 1 and phase or 2 - phase
    local x = K.EASING.in_out_cubic(progress) * 250
    K.Box({modifier = M:width(300):height(64):background("#252B31"):clip()}, function()
        K.Box({modifier = M:offset(x, 12):size(40):background("#81C9BC", 6):tag("motion_pingpong_dot")})
    end)
end
if running.value then
    K.key("loop", function() draw(K.clock()) end)
else
    draw(0)
end
```

После остановки объект возвращается в начало. При запуске K.clock создаётся заново; скрытые часы не продолжают обновлять страницу. Отрисовка находится в той же области композиции, что и часы.

### Перетаскивание с пружинным возвратом

Перетащите квадрат и отпустите: он возвращается к центру. Во время жеста цель следует мыши без запаздывания.


### Цепочка по завершению переходов

Каждый следующий участок начинается, когда предыдущий tween дошёл до цели. Длительность шага можно менять прямо во время сценария.

```lua
local stage = K.state(0)
local duration = K.state(0.7)
local phase = stage.value
local target = phase % 2
local value = K.animate(target, K.tween(duration.value, "in_out_cubic"))
local arrived = value == target
K.effect(function()
    if arrived and phase > 0 and phase < 4 then stage.value = phase + 1 end
end, phase, arrived)
UI.Slider({label = "Длительность следующего шага", min = 0.2, max = 1.5, value = duration.value,
    on_change = function(v) duration.value = v end})
UI.Button({text = "Запустить цепочку", enabled = phase == 0 or (phase == 4 and arrived),
    on_click = function() stage.value = 1 end})
local points = {{12, 12}, {240, 12}, {240, 108}, {12, 108}, {12, 12}}
local index = math.max(1, phase)
local p = phase == 0 and 0 or phase % 2 == 1 and value or 1 - value
local from, to = points[index], points[index + 1]
local x = from[1] + (to[1] - from[1]) * p
local y = from[2] + (to[2] - from[2]) * p
K.Text(phase == 0 and "Ожидание запуска" or phase == 4 and arrived and "Цепочка завершена" or "Шаг " .. phase .. " / 4")
K.Box({modifier = M:width(300):height(168):background("#252B31"):clip()}, function()
    K.Box({modifier = M:offset(x, y):size(40):background("#EAC778", 6)})
end)
```

Tween точно фиксирует конечное значение, поэтому сравнение с целью здесь допустимо. Пружина может пересекать цель до остановки: для неё одного сравнения позиции недостаточно.

### Временная шкала: пауза и обратный ход

Управляйте четырёхсекундной сценой: воспроизведение, пауза, обратный ход и перемотка. Все свойства вычисляются из одной позиции.

```lua
local start = K.state(0)
local direction = K.state(0)
local run = K.state(0)
K.key(run.value, function()
    local position = start.value
    if direction.value ~= 0 then
        position = math.max(0, math.min(1, start.value + K.clock() / 4 * direction.value))
    end
local finished = direction.value == 1 and position == 1 or direction.value == -1 and position == 0
K.effect(function()
    if finished then
        start.value = position
        direction.value = 0
        run.value = run:peek() + 1
    end
end, finished)
local function play(next_direction)
    start.value = position
    direction.value = next_direction
    run.value = run:peek() + 1
end
K.Row({spacing = 6}, function()
    UI.Button({text = "Вперёд", compact = true, on_click = function() play(1) end})
    UI.Button({text = "Пауза", compact = true, on_click = function() play(0) end})
    UI.Button({text = "Назад", compact = true, on_click = function() play(-1) end})
end)
UI.Slider({label = "Перемотка", min = 0, max = 1, value = position, on_change = function(v)
    start.value = v
    direction.value = 0
    run.value = run:peek() + 1
end})
local function interval(a, b)
    return K.EASING.in_out_cubic(math.max(0, math.min(1, (position - a) / (b - a))))
end
local enter = interval(0, 0.25)
local grow = interval(0.25, 0.65)
local exit = interval(0.8, 1)
K.Text(string.format("Время %.2f / 4.00 с", position * 4))
K.Box({modifier = M:width(320):height(150):background("#252B31"):clip()}, function()
    K.Box({modifier = M:offset(12 + enter * 100, 24 - exit * 20):size(64 + grow * 120, 80)
        :alpha(enter * (1 - exit)):background({0.35 + grow * 0.3, 0.65, 0.75 - grow * 0.3, 1}, 6)})
end)
end)
```

При паузе сохраняется текущая позиция, а K.clock удаляется из композиции. Новый ключ запуска начинает отсчёт с сохранённой позиции. Вся сцена синхронизирована одной шкалой.

### Бросок и фиксированный шаг физики

Физика работает в on_frame с шагом 1/120 с. Перетаскивание передаёт скорость отпускания в координатах родителя.

```lua
local body = K.remember(function() return {x = 90, y = 30, vx = 0, vy = 0, rest = 0, held = false} end)
local position = K.state({x = body.x, y = body.y})
K.on_frame(function(dt)
    body.rest = body.rest + math.min(dt, 0.1)
    local step = 1 / 120
    while body.rest >= step do
        body.rest = body.rest - step
        if not body.held then
            body.vy = body.vy + 500 * step
            body.x, body.y = body.x + body.vx * step, body.y + body.vy * step
            if body.x < 0 then body.x, body.vx = 0, math.abs(body.vx) * 0.8 end
            if body.x > 284 then body.x, body.vx = 284, -math.abs(body.vx) * 0.8 end
            if body.y < 0 then body.y, body.vy = 0, math.abs(body.vy) * 0.8 end
            if body.y > 164 then body.y, body.vy = 164, -math.abs(body.vy) * 0.75 end
        end
    end
    position.value = {x = body.x, y = body.y}
end)
local p = position.value
K.Box({modifier = M:size(320, 200):background("#252B31"):clip()}, function()
    K.Box({modifier = M:offset(p.x, p.y):size(36):background("#81C9BC", 18):draggable({
        on_event = function(e)
            if e.type == "start" then body.held = true
            elseif e.type == "move" then
                body.x = math.max(0, math.min(284, body.x + e.parent_dx))
                body.y = math.max(0, math.min(164, body.y + e.parent_dy))
            elseif e.type == "end" then
                body.held, body.vx, body.vy = false, e.velocity_x, e.velocity_y
            elseif e.type == "cancel" then body.held, body.vx, body.vy = false, 0, 0 end
        end
    })})
end)
```

## Обновление этого файла

Файл генерируется из документации, аннотаций и исходных примеров галереи.
После изменений Kompot пересобери его командой:

```sh
python3 tools/build_ai_guide.py
```

Для извлечения примеров нужен `lua` в PATH. Инструкции в начале файла находятся
в `tools/build_ai_guide.py`; редактируй их там, чтобы пересборка сохранила правки.
Документацию и аннотации обновляй в исходных файлах проекта.

Этот справочник предназначен для разработки и передачи нейросети.
`tools/package.py` исключает его из релизного архива.
