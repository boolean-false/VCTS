# Превью в VS Code

Расширение **Kompot Lens** позволяет смотреть интерфейс рядом с Lua-кодом,
нажимать кнопки и проверять анимации без запуска игры.

## Первое превью

1. Установите [Kompot Lens](https://marketplace.visualstudio.com/items?itemName=BooleanFalse.kompot-lens)
2. Откройте в VS Code папку своего пака или проекта. Пак `kompot` должен лежать рядом с вашим паком в каталоге паков.
3. Добавьте `K.preview` в Lua-модуль своего пака, например `modules/previews.lua`:

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

K.preview("Счётчик", {
    width = 360,
    height = 120,
    theme = UI.theme(),
}, function()
    local count = K.state(0)
    UI.Button({
        text = "Нажато: " .. count.value,
        on_click = function()
            count.value = count:peek() + 1
        end,
    })
end)
```

Сохраните файл и выполните **Kompot: Открыть превью** (`Ctrl+K V`, на macOS -
`Cmd+K V`). Нажмите **Интерактивно**, чтобы проверить кнопку.

В одном файле можно объявить несколько превью с разными именами - например,
для обычного и узкого окна. Внутри используйте те же компоненты, состояния
и модификаторы, что и в игровом интерфейсе.

## Настройки `K.preview`

| Поле | Значение |
|---|---|
| `width`, `height` | Размер области превью; по умолчанию 400×300 |
| `theme` | Тема интерфейса или функция, которая её возвращает; по умолчанию базовая тема Kompot |
| `padding` | Отступ от краёв; по умолчанию 16. Значение `0` убирает отступ |
| `group` | Название группы, например `"Кнопки"` |
| `hook_diagnostics` | Подробные места вызова хуков; по умолчанию `true`. Проверка типов и количества хуков действует всегда |

Укажите ту же тему, которую используете в игре, чтобы совпадали оформление
и шрифты. Для другого размера окна создайте отдельное превью с тем же содержимым.

## Работа в редакторе

- Сохранение файла обновляет превью. Для обновления при наборе выберите `live`
  в настройке `kompot.previewUpdateMode`.
- Масштаб и кнопка **Вписать** помогают просматривать широкие интерфейсы.
- В интерактивном режиме работают состояния, кнопки и анимации.
- Команда **Kompot: Добавить превью** вставляет шаблон в текущий файл.

Если пак не найден, нажмите **Выбрать каталог паков** в превью. Выбор
сохраняется для проекта. Для подсказок и проверки типов достаточно зависимости
`"kompot"` в `package.json`, даже если сам пак ещё не установлен.

Чтобы использовать свой Lua или LuaJIT, укажите путь в `kompot.luaExecutable`.
Для встроенных текстур и растрового шрифта движка может понадобиться путь
к каталогу `res` в `kompot.enginePath`.

О подключении своих шрифтов - в [руководстве по шрифтам](FONTS.md).

Нативный текстовый ввод, каретку, выделение и подсветку проверяйте в игре.

## Формат скруглений для внешних отрисовщиков

В `kompot-preview/1` поле `radius` у `rect`, `border`, `shadow` допускает
число или объект `{top_left, top_right, bottom_right, bottom_left}`. Все
значения уже ограничены размерами фигуры. Старый числовой формат сохраняется.
Скруглённый `clip` представлен примитивом `layer` с `mask_radius` в таком же
формате. Маска применяется один раз к собранному содержимому слоя; вложенные
`prims`, `transform` и `source_bounds` остаются частью обычного формата слоя.
Маску нельзя терять при объединении соседних преобразований.

### Shape

Новые формы сериализуются в поле `shape` у `rect`, `border`, `shadow` и в
`mask_shape` у `layer`. Контур имеет `kind: "rounded" | "cut"` и четыре
числовых поля `top_left`, `top_right`, `bottom_right`, `bottom_left` в пикселях.
Проценты разрешаются по исходной геометрии элемента до передачи отрисовщику;
размытие тени в размер для расчёта процентов не входит. `circle` разрешается
в `rounded`, а `rectangle` использует прежний прямоугольный примитив.
Поля `radius` и `mask_radius` сохраняются для старых вызовов. Новые
отрисовщики сначала проверяют `shape`/`mask_shape`, затем старые поля.
Идентичность кэша учитывает тип контура: одинаковые размеры rounded и cut
дают разные текстуры. Маска применяется один раз к собранному слою.
