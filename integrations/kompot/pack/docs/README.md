# Документация Kompot

Kompot состоит из ядра `kompot:kompot` и встроенной дизайн-системы `kompot:ui`.
Обзор состояния, раскладки и модификаторов описан в руководствах ниже.

Если вы пишете пак, использующий kompot:

1. [Первый экран](QUICKSTART.md) показывает полный пак: зависимость, клавишу,
   окно и Lua-код с освобождением интерфейса.
2. [Kompot UI](UI.md) объясняет тему и стандартные компоненты.
3. [Игровые компоненты](GAME_UI.md) описывают инвентарь, предметы и HUD.
4. [Преобразования, кадры и перетаскивание](MOTION.md) показывают вращение,
   масштаб, Canvas и обновление физики.
5. [Текстовый ввод](TEXT_INPUT.md) нужен, если в окне есть редактируемые поля.
6. [Состояние, таблицы и формы](STATE.md) объясняет `patch`, `update_field`,
   `K.copy`, `K.form`.

Если делаете свою дизайн-систему, начните с [темы и общего контракта](DESIGN_SYSTEM.md).
Затем пригодятся [шрифты](FONTS.md), [текстурные скины](SKINS.md) как пример готовой системы.

[Превью в VS Code](PREVIEW.md) позволяет проверять интерфейсы без запуска игры.

Коротко о терминах:

- **Компонент** - функция, которая строит часть интерфейса, например кнопку.
- **Тема** - таблица с цветами, шрифтами и размерами.
- **`props`** - свойства, переданные компоненту в таблице.
- **Модификатор** (`modifier`) - цепочка настроек размера, отступов и ввода.
- **`payload`** - данные, которые источник передаёт цели при перетаскивании.
