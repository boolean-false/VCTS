# Kompot UI

Фирменная дизайн-система Kompot. Она поставляется **внутри
пака `kompot`** и подключается как `require "kompot:ui"`. 
Ядро `kompot:kompot` от неё не зависит. Другую систему можно реализовать самому
или установить отдельным паком.

Для игрового оформления достаточно одного пака `kompot`.
- [Игровые компоненты: ItemSlot, InventoryGrid, Hotbar, HUD, MachinePanel](GAME_UI.md).
- [Полный пример первого мода](QUICKSTART.md).

## Общая форма Shape

С версии 1.1.0 `K.Shape` задаёт общую форму для `background`, `border`,
`shadow`, `clip` и `focus_shape`. Форма не зависит от конкретного размера
элемента: размеры её углов разрешаются после раскладки.

| Конструктор | Результат |
|---|---|
| `K.Shape.rectangle()` | Прямоугольник с прямыми углами |
| `K.Shape.circle()` | Круг для квадрата, капсула для прямоугольника |
| `K.Shape.rounded(size)` | Круглые углы; один размер или таблица четырёх углов |
| `K.Shape.cut(size)` | Прямые срезы; размер измеряется вдоль прилегающих сторон |
| `K.Shape.px(value)` | Размер в пикселях; обычное число означает то же самое |
| `K.Shape.percent(value)` | От 0 до 100 процентов меньшей стороны элемента |

```lua
local S = K.Shape
local shape = S.cut({
    top_left = S.percent(50),
    top_right = S.px(8),
    bottom_right = 0,
    bottom_left = 16,
})

K.Box({modifier = K.M:size(240, 120)
    :shadow(8, shape)
    :background("#386F94", shape)
    :border(2, "#FFFFFF", shape)
    :clip(shape)
    :padding(12)
}, function()
    K.Text("Общая форма")
end)
```

Для одинаковых углов используйте `S.rounded(12)` или
`S.rounded(S.percent(25))`. Таблица принимает физические `top_left`,
`top_right`, `bottom_right`, `bottom_left`; незаданные углы равны нулю.
В одной форме можно смешивать пиксели и проценты, в том числе дробные.
Один дескриптор можно использовать у элементов разных размеров: например,
25% у элемента 200×80 даст 20 px, а у 200×40 - 10 px. Суммы соседних
углов ограничиваются длиной стороны с пропорциональным уменьшением всех
четырёх значений.

Модификатор сохраняет копию формы. Для изменения через состояние создайте
новую форму и передайте её при следующей композиции. Перемещение или смена
цвета не меняет текстуру геометрии; изменение формы или размеров обновляет её.
У `clickable` и `focusable` опция `focus_shape` задаёт форму рамки фокуса.
Старое имя `focus_radius` также принимает форму; при указании обоих
используется `focus_shape`.

Фон рисует форму, рамка обводит её изнутри, тень повторяет силуэт, а `clip`
обрезает последующее содержимое и области ввода. Для срезанных углов толщина
рамки измеряется перпендикулярно диагональному краю. Прямоугольный `clip`
сохраняет быстрый путь без растровой маски; остальные формы используют слой
с теми же ограничениями, что описаны ниже для скруглений. Нативное поле ввода
можно оформить любой формой фона и рамки, но помещать внутрь фигурного `clip`
пока нельзя. Произвольные контуры, логические `start/end` и морфинг в этот API
не входят.

## Скругление отдельных углов

`background`, `border`, `shadow`, `clip` и `focus_radius` принимают число
для всех углов или таблицу с радиусами в пикселях:

```lua
local corners = K.rounded_corners({
    top_left = 24,
    top_right = 8,
    bottom_right = 0,
    bottom_left = 16,
})

K.Box({
    modifier = K.M:size(240, 120)
        :shadow(8, corners)
        :background("#386F94", corners)
        :border(2, "#FFFFFF", corners)
        :clip(corners)
        :padding(12),
}, function()
    K.Text("Каждый угол отдельно")
end)
```

Таблицу можно передать напрямую; `K.rounded_corners` проверяет и копирует её
для повторного использования. Незаданные углы имеют радиус `0`. Имена задают
физические углы, независимо от направления текста. Радиусы неотрицательные;
если сумма соседних радиусов больше стороны, все четыре уменьшаются
пропорционально. `math.huge` означает половину меньшей стороны; старые
вызовы `background(color, 12)` и `clip()` сохраняют своё поведение.

Фон рисует только свою форму. `clip(corners)` обрезает последующие модификаторы,
картинки и дочерние элементы, включая области ввода. Поэтому тень и рамку
обычно задают перед `clip`, а внутренний отступ - после него. Для картинки
или текстурного фона используйте `clip(corners):background_image(material)`.
`fit = "cover"` у картинки управляет масштабированием, а `clip` - формой обрезки.

В VoxelCore скруглённый `clip` использует растровый слой с прозрачной маской.
Вложенные маски и преобразования поддерживаются; обновление содержимого
проходит через GPU-кадр и может появиться с задержкой в несколько кадров.
Размер исходного и результирующего слоя ограничен 2048 пикселями по каждой
оси, как у `rotate`/`scale`.
Нативные `TextInput`/`BasicTextField` внутри скруглённого `clip` пока не поддерживаются:
задавайте полю скруглённые фон и рамку, оставляя его обрезку прямоугольной. `clip(0)` использует обычный
контейнер без растрового слоя.

## Встроенный справочник

В мире с подключённым паком `kompot` нажмите **F12**, чтобы открыть
**справочник Kompot** с живыми примерами.
Клавишу можно переназначить в настройках управления «Kompot / Справочник»
(`kompot.gallery`). Кнопка закрытия находится в правом верхнем углу.

Три самостоятельных раздела:

- **Игровые окна**: сундук, пауза, верстак, HUD, настройки и состояния ячеек.
  Это первый экран галереи; примеры показаны поверх мира. Кнопка «Код»
  открывает описание и Lua-фрагмент.

- **Ядро**: раскладка, модификаторы, состояние, жизненный цикл,
  взаимодействие, графика, текстовый ввод, анимация, прокрутка и интеграция.
  В группе «Анимация» есть последовательности, параллельные переходы,
  каскадное появление, ключевые кадры с перемоткой, циклы, волны, орбиты,
  смена сцен и перетаскивание с пружинным возвратом. Отдельные примеры
  показывают цепочку по завершению переходов и шкалу с паузой и обратным ходом.
- **Компоненты**: компоненты дизайн-системы, типографика, темы и законченные
  примеры настроек игры, инвентаря и HUD.

В разделах ядра и компонентов слева находится сгруппированный список примеров.
Поиск работает по названию, описанию и именам API, включая кириллицу без учёта
регистра. Для каждого раздела запоминаются выбранная страница и запрос.
При ширине окна меньше 900 пикселей список открывается кнопкой «Разделы и поиск».

В «Оформлении» меняются акцент и плотность всей оболочки и примеров.
Настройки можно сбросить. Страницы темизации отдельно показывают создание
и наследование тем через API.

У каждого живого примера собственное состояние и кнопка «Сбросить».
Уход со страницы завершает её жизненный цикл; при возвращении пример
создаётся заново, а позиция прокрутки страницы сохраняется. Закрытие справочника
освобождает компоненты, таймеры и нативные поля ввода.

Отображаемый исходник и живая демонстрация используют один код из каталога.
Полный фрагмент включает импорты, композицию и вызов `K.mount`; его можно
выделить в поле кода и скопировать Ctrl+C. Длинный код прокручивается внутри
поля. Разделы подключения и регистрации превью содержат самостоятельные
скрипты: они не запускаются внутри открытого справочника.

Примеры `editor_state` и `presentation` включаются автоматически, если
бэкенд обнаружил API текстовой раскладки VoxelCore. На прежнем движке
показываются объяснение зависимости и код без попытки создать несовместимое поле.

Открыть справочник из своего инструмента: `require("kompot:ui").open_gallery()`.
Обычный `require "kompot:ui"` не загружает каталог и не создаёт его интерфейс.
Выполнения произвольного Lua-кода в игровом справочнике нет.

### Устройство каталога

- `modules/ui/gallery.lua`: оболочка, навигация, поиск, оформление.
- `modules/ui/guide.lua`: реестр, поиск, компиляция поставляемых примеров.
- `modules/ui/guide/components.lua`: компоненты и текстовые поля.
- `modules/ui/guide/foundation.lua`: механизмы ядра и темизация.
- `modules/ui/guide/animations.lua`: простые и сложные анимации ядра.
- `modules/ui/guide/recipes.lua`: игровые интерфейсы и интеграция.
- `modules/ui/previews.lua`: превью из того же каталога для редактора.

Новый пример регистрируется через `G.add(group, id, title, description, apis,
source, opts)`. `id` уникален, `apis` участвует в поиске, `source` содержит
самодостаточное тело композиции с доступными `K`, `UI`, `M`. Проверка галереи
компилирует и компонует все примеры отдельно, чтобы они не зависели от
состояния соседних страниц. Пользовательский код этот загрузчик не принимает.

### Фрагменты Lua в своём интерфейсе

`UI.Lua` и `UI.TextField` используют общее основание `K.BasicTextField`,
но оформляются независимо. VoxelCore рисует многострочный исходник
с нативной подсветкой Lua, выделением и копированием. Поле имеет
`editable = false`: код не редактируется и не выполняется.
Параметры `lines` и `height` ограничивают видимую область длинного фрагмента.

```lua
UI.Lua({
    code = [[local count = K.state(0)
K.Text(count.value)]],
    title = "Состояние",
    line_numbers = true,
    modifier = K.M:fill_max_width(),
})
-- Для короткого фрагмента: UI.Lua("K.Text('Привет')")
```

## Плотность и поверхности

По умолчанию используется `density = "comfortable"`: кнопки высотой
28/36/44 px, отступ панели 16 px, промежуток 12 px. Для плотных инструментов:

```lua
local theme = UI.theme({density = "compact"})
-- Или только для части экрана:
UI.Theme({density = "compact"}, function()
    UI.Button({text = "Действие"})
end)
```

`compact` сохраняет прежние основные размеры: кнопки 24/26/28 px,
отступ панели 10 px, промежуток 6 px. Скругления и палитра общие.
Галерея использует стандартную плотность; мод выбирает её при создании темы.
Вложенная тема наследует плотность и настройки размеров родителя.
При явной смене плотности размеры сбрасываются к выбранному набору;
`metrics` в том же вызове переопределяет этот набор.

`Panel` по умолчанию имеет фон без полосы. `variant = "flat"` оставляет
заголовок и отступы без фона; `variant = "accent"` добавляет полосу.
`accent` задаёт цвет полосы, но сам по себе её не включает. Для групп внутри одной поверхности используйте
отступы и заголовки, добавляя карточки там, где нужно выделить содержимое.

При смене `accent` цвет `on_primary` автоматически выбирается светлым или
тёмным. Его можно явно задать через `colors`. Существующие интерфейсы
с фиксированными размерами контейнеров следует проверить с новой плотностью
или перевести на `compact`.

## Быстрый старт

В `package.json` мода добавьте `"dependencies": ["kompot"]`. Ниже показано
содержимое экрана; расположение файлов и открытие окна есть в
[полном примере](QUICKSTART.md).

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

local function Screen()
    local enabled = K.state(true)
    local applied = K.state(false)
    UI.Panel({title = "Настройки"}, function()
        UI.Checkbox({checked = enabled.value, label = "Звуки",
            on_change = function(v) enabled.value = v end})
        UI.Button({text = "Применить", variant = "primary",
            on_click = function() applied.value = true end})
        if applied.value then K.Text("Настройки применены") end
    end)
end

local handle = K.mount({theme = UI.theme(), content = Screen})
-- handle:dispose()
```

## Тема

### Иконки

Kompot UI поставляет 63 пиксельные иконки в атласе `kompot_ui_icons`.
Они рисуются на сетке 16×16 без сглаживания и тонируются цветом элемента.
`UI.theme()` задаёт этот атлас в `icons`, поэтому внутри темы достаточно
`K.Icon("settings", {size = 20})`. Также доступен явный источник
`K.Icon("kompot_ui_icons:settings")`.

Ядро Kompot содержит только механизм `K.Icon`: без `theme.icons` для короткого
имени нужно передать полное имя `атлас:иконка`. Своя дизайн-система может
указать свой атлас в теме.

### Скин

Панели, кнопки и углубления используют четыре PNG в
`textures/kompot_ui_skin/`. Для своего оформления достаточно нарисовать PNG
и указать источники в `UI.theme({skin = {panel = "my_skin:panel", ...}})`.
Подробности о размерах, границах и цветных текстурах - в [руководстве по
скинам](SKINS.md).

`UI.theme(opts)` возвращает независимую таблицу настроек. Непереданные
значения берутся из фирменной темы. `UI.current()` возвращает текущую тему
Kompot UI; `UI.DEFAULT` - фирменную. Константы `UI.PALETTE`, `UI.TYPE`,
`UI.METRICS`, `UI.MOTION` описывают исходные значения; менять
оформление следует через тему, а не изменением этих констант.

```lua
local theme = UI.theme({
    name = "my-mod",
    accent = "#E3AF67", -- свой цвет мода
    panel_alpha = 0.96,
    colors = {surface = "#20242B", on_surface = "#F4F4F4"},
    type = {body = {font = "kompot_16", size = 16}},
    metrics = {control = 32, control_lg = 38, pad = 12, gap = 8},
    shapes = {control = 4, panel = 6, card = 4, field = 4},
    motion = {hover = K.tween(0.12)},
    components = {Button = {size = "lg"}, Panel = {spacing = 10}},
})
```

| Настройка | Назначение |
|---|---|
| `colors` | Общие роли `primary`, `on_primary`, `surface`, `on_surface`, `background`, `surface_raised`, `outline`, `error`, `success`, `warning`; подробные роли `action`, `action_hover`, `panel_bg`, `sunken`, `control`, `text`, `muted`, `dim`, `key` и другие |
| `accents` | Необязательные имена цветов, определённые самим модом; встроенных наборов нет |
| `skin` | PNG для `panel`, `button`, `button_pressed`, `inset`; можно заменить отдельные источники |
| `type` | `caption`, `body`, `label`, `strong`, `title`, `heading`, `display`, `mono`; частичное переопределение стилей |
| `metrics` | Размеры контролов, ширина и отступы панелей, промежутки, размеры панелей инструментов |
| `shapes` | Радиус кнопок (`control`), панелей (`panel`), карточек (`card`) и полей (`field`) |
| `motion` | Анимации `hover`, `fast`, `normal` |
| `components` | Значения свойств по умолчанию: `Button = {variant = "primary"}`. Явные свойства компонента имеют приоритет, включая `false` и `0` |
| `ui` | Частичная замена реализаций общего контракта `K.ui()` |

При создании темы общие роли согласуются с подробными: `primary` - с
`accent`, `surface` - с `panel`, `on_surface` - с `text`. Изменение фирменного
акцента также обновляет заливку главного действия; явно указанные `action`
и `action_hover` имеют приоритет. Строковые цвета принимаются в формате hex.

## Вложенная тема

`UI.Theme(overrides, content)` наследует **текущую** тему Kompot UI и меняет
её только внутри `content`. После выхода восстанавливаются настройки
родителя. Компоненты читают шрифты, цвета и анимации из текущей темы.

```lua
UI.Theme({accent = "#E3AF67", components = {Button = {size = "lg"}}}, function()
    UI.Button({text = "Крупная кнопка", variant = "primary"})
    UI.Button({text = "Маленькая", size = "sm"}) -- явное свойство важнее
end)
```

Готовую полную тему можно передать обычному `K.Theme(theme, content)` или
`K.mount({theme = theme, ...})`. Для частичного изменения с пересчётом
зависимых цветов используйте `UI.theme` / `UI.Theme`.

## Свои компоненты и общий контракт

Специфичные элементы мода строятся поверх Kompot UI и живут **в самом моде**.
Например, экран настроек конкретного приложения принадлежит этому приложению,
а кнопки, поля, списки и окна - Kompot UI.

В компоненты `Button`, `Panel`, `Card`, `Window`, `Dialog` можно передать
функцию собственного содержимого. Для полностью переносимых экранов
используйте `K.ui()` ([контракт](DESIGN_SYSTEM.md)). Компоненты контракта
можно заменить для поддерева, сохранив остальные:

```lua
UI.Theme({ui = {
    Button = function(props, content)
        -- Своя реализация или обёртка над UI.Button.
        UI.Button(props, content)
    end,
}}, function()
    K.ui().Button({text = "Своя кнопка"})
    K.ui().Checkbox({checked = true, label = "Стандартный флажок"})
end)
```

`UI.Button` всегда обозначает фирменную реализацию, `K.ui().Button` -
реализацию из текущего контракта. Прямые `UI.TextField`, `UI.Segmented` и
`UI.ListItem` также доступны. У контракта `secondary` соответствует обычной
кнопке; `Segmented` выбирает по индексу, а `Choice` - по значению.

## Компоненты

| Компонент | Главное |
|---|---|
| `Panel(props, content)` | Фон поверх мира, необязательная полоса-акцент, заголовок, `header` справа. Непрозрачна для указателя (`block_pointer`): щелчок не уходит в мир |
| `SplitPane` | Две области с перетаскиваемым разделителем, ограничениями размеров и управлением стрелками |
| `Window` | Панель поверх всего с кнопкой «Закрыть», по центру; `modal` - с затемнением |
| `Dialog` | Подтверждение: `title`, `text` (разметка md), `confirm`, `dismiss` |
| `Button` | `variant`: `default`, `primary`, `danger`, `ghost`, `toggle` (с `selected` - включённое условие); `size`: `sm`, `md`, `lg`; `icon`, `trailing`, `compact`, `min_width`, `tooltip`, `on_right_click` |
| `IconButton`, `ToolButton` | Квадратная кнопка со значком; кнопка панели инструментов (значок 24, размеры из темы, выбранная обведена) |
| `Checkbox`, `Switch` | Квадратный флажок, плоский переключатель |
| `Choice` | Выбор значения рядом кнопок: `options = {{value, text}}`, `columns` |
| `Stepper` | «Подпись: значение [-] [+]» - числовые настройки |
| `Slider` | Плоская дорожка, прямоугольный бегунок, подпись и значение |
| `Tabs` | Текстовые вкладки с полосой снизу |
| `Field`, `LabeledField`, `VectorField` | Поле ввода (рамка в фокусе, набранный текст не перетирается извне), с подписью, три поля X/Y/Z |
| `Menu`, `MenuItem`, `MenuDivider`, `MenuBar` | Выпадающее меню с сочетаниями клавиш; строка меню с названием и действиями |
| `Bar`, `key_chips(list)` | Строка подсказок или состояния (разметка md); подсказки клавиш: `{{"ЛКМ", "рисовать"}}` |

| `ListRow` | Строка списка с кнопкой × |
| `Slot`, `Card`, `Preview` | Ячейка с картинкой (блоки, предметы, число в углу), тёмная карточка, картинка на подложке |

Порядок всплывающих слоёв: уведомление −1, окна 0, диалог 10, меню 20,
подсказки 30.

Компонент Kompot UI в чужой теме использует фирменную тему по умолчанию.

## Превью

- `modules/ui/previews.lua` - общие компоненты, вложенные темы, списки.

### Уведомления и диалоги

Окна и диалоги по умолчанию без полосы. `variant = "accent"` включает её,
`accent` задаёт цвет. Эти свойства
проходят через `Window` и `Dialog` к `Panel`. `Dialog.icon` задаёт иконку заголовка.

```lua
UI.Toast({text = "Настройки сохранены", tone = "success"})
UI.Toast({text = "Не удалось сохранить", tone = "error"})
UI.Toast({text = "Обычное уведомление"})
```

`Toast` использует цвета темы, её плотность и пиксельную поверхность. По умолчанию
показывает нейтральную иконку; смысловые варианты добавляют цветную иконку
и лёгкую тонировку фона. `icon` заменяет иконку, `icon = false` скрывает её.
`accent` меняет цвет иконки, а полоса появляется только при `variant = "accent"`.
Общие значения можно задать через `UI.theme({components = {Toast = {...}}})`.
Время показа контролирует вызывающий код: пустой `text` скрывает уведомление.

### Палитра мода

Стандартная палитра Kompot UI - матовые серо-оливковые поверхности.
Основной цвет дают предметы и состояния игры.
Цвет подсказок клавиш независим от `warning`: предупреждения не используются
для обычных сочетаний клавиш. Выбранные и включённые элементы используют
одну акцентную семью цветов.

Собственную палитру храните в моде и передавайте в `UI.theme({colors = ...})`.
Например, Contour хранит прежнюю сине-серую палитру в `contour:ui` и использует
`density = "compact"`. Сам Kompot от Contour не зависит.

## Раздвижные панели

`SplitPane` делит ограниченную по ширине и высоте область на две панели.
`first` и `second` - функции содержимого. По умолчанию панели расположены
слева направо; `orientation = "vertical"` размещает их сверху вниз.

```lua
local width = K.state(240)
UI.SplitPane({modifier = K.M:fill_max_width():height(400),
    size = width.value, min_first = 160, max_first = 400, min_second = 200,
    on_change = function(value) width.value = value end,
    first = function() K.Text("Навигация") end,
    second = function() K.Text("Редактор") end,
})
```

- `size` - размер первой панели в пикселях без разделителя. Вместе с
  `on_change(value)` позволяет хранить размер снаружи компонента.
- Без `size` компонент хранит размер сам; `default_size` задаёт начальное
  значение (240). `on_change` также можно использовать в этом режиме.
- `min_first` и `min_second` (0) ограничивают обе панели, `max_first` - первую.
  При конфликте минимальный размер имеет приоритет над `max_first`.
  Если места меньше суммы минимумов, они уменьшаются пропорционально.
  Изменение доступного места не перезаписывает выбранный размер.
- `divider_size` (12) задаёт ширину области захвата; `divider_modifier`
  позволяет добавить, например, `tag`. Содержимое панелей обрезается по их границам.
- `enabled = false` запрещает изменение размера пользователем.
- После фокусировки разделителя стрелки вдоль оси меняют размер на `step`
  пикселей (10). Перетаскивание продолжается за пределами разделителя.

В галерее Kompot разделитель меняет ширину навигации. Размер сохраняется в течение
сеанса справочника, включая переходы между страницами и узкую раскладку.

## Перемещение и изменение размеров окон

У `Window` есть две независимые возможности, выключенные по умолчанию:
`draggable = true` включает перемещение за заголовок, `resizable = true` -
изменение размеров за четыре края и четыре угла. Кнопки заголовка сохраняют
своё действие. Курсор показывает направление изменения размера.

```lua
local bounds = K.state(nil)
UI.Window({title = "Редактор", draggable = true, resizable = true,
    width = 520, height = 320, min_width = 300, min_height = 180,
    max_width = 900, max_height = 700,
    bounds = bounds.value,
    on_bounds_change = function(value) bounds.value = value end,
}, function()
    K.Column({modifier = K.M:fill_max_size()}, function()
        K.Text("Рабочая область")
    end)
end)
```

- `width`, `height` задают исходные размеры; без `height` высота зависит от
  содержимого до первого перемещения или изменения размера.
- `min_width`, `min_height` (200 и 100) и необязательные `max_width`, `max_height`
  ограничивают размеры при `resizable`. Минимум имеет приоритет над максимумом.
  Фактический размер также ограничен доступным экраном.
- `bounds = {x, y, width, height}` задаёт управляемую геометрию в координатах
  хоста Kompot. `on_bounds_change(bounds)` вызывается при перетаскивании.
  Без `bounds` геометрия хранится внутри компонента; callback можно использовать
  и в этом режиме. Для сохранения после удаления компонента храните `bounds` снаружи.
- До первого перемещения действует `placement`. После него положение ограничивается
  границами хоста; уменьшение экрана не оставляет заголовок за его пределами.
- Содержимое изменяемого окна получает доступную область под заголовком и
  обрезается по её границам. Используйте `fill_max_size`, `weight`, прокрутку
  или `SplitPane`, чтобы оно приспосабливалось к размерам.
- `modifier` применяется к окну, `title_modifier` - к области заголовка без кнопок.
  `z` по-прежнему задаёт порядок окон; перемещение не меняет его автоматически.

Для собственного оформления `Panel` также принимает `title_modifier`,
`content_modifier` (обёртка содержимого) и `fill_height` (заполнение заданной высоты).

`M:block_pointer()` блокирует также нативные поля VoxelCore под областью:
они не получают наведение, выделение и щелчки сквозь неё. Это действует и для
немодальных окон; неперекрытая часть фонового интерфейса остаётся доступной.
Пример «Перемещение и размер окон» в справочнике создаёт новый редактор при каждом
нажатии кнопки, с независимыми текстом и геометрией.
