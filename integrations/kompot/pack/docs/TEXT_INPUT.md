# Текстовый ввод

## Уровни

- `K.TextInput` передаёт параметры нативному textbox VoxelCore.
- `K.BasicTextField` связывает ввод с состоянием, не добавляя рамку, фон или подпись.
- `UI.TextField` добавляет оформление поля и подписи.
- `UI.Lua` использует `BasicTextField` напрямую и добавляет оформление фрагмента кода.

```lua
local K = require "kompot:kompot"
local UI = require "kompot:ui"

local FieldDemo = K.component(function()
    local text = K.state("Привет")
    K.Column({spacing = 8}, function()
        K.BasicTextField({
            state = text,
            modifier = K.M:width(320):height(40),
        })
        UI.TextField({state = text, label = "Тот же текст"})
    end)
end)
```

`state` - обычный Kompot State со строкой. Изменения пользователя записываются
в него перед вызовом необязательного `on_change(text)`. Внешние изменения
применяются и во время фокуса. Нельзя одновременно передавать `state` и `value`.
`state.value` должен быть строкой, `lines` - положительным целым числом.
Пустая строка допустима. В `value` отсутствие значения означает пустую строку.
Размер можно задать через modifier; без явной высоты поле измеряет `lines`
видимых строк и внутренние отступы. `UI.TextField` сохраняет тематическую
высоту однострочного контрола; многострочный измеряется по шрифту.

Для совместимости доступен `value/on_change`: во время фокуса локальный
черновик защищает ввод от повторной передачи старого значения. После потери
фокуса используется внешнее `value`. Если нужно программно менять текст
активного поля, следует использовать `state`. Если изменение отклонено
владельцем, после потери фокуса вернётся прежнее `value`. Смена режима
`editable` или источника `state` очищает локальный черновик.

`editable = false` запрещает изменение пользователем, сохраняя нативное
выделение и копирование. Программные обновления текста остаются доступны.
`on_submit`, `on_focus` и `on_defocus` передаются компоненту-владельцу.

## Граница нативного бэкенда

Ввод, переносы, hit testing, прокрутка и история редактирования принадлежат
textbox VoxelCore. По умолчанию он также рисует текст и декорации.
`presentation` позволяет Kompot рисовать текст, выделение и каретку по
**раскладке самого textbox**, без повторного вычисления ширин и переносов.
Фон, номера строк и полоса прокрутки остаются нативными.

Обычные поля работают без этих расширений. Для `presentation` и `editor_state`
нужна сборка VoxelCore с API `selection`, `textLayout` и `externalRendering`.
Если этих возможностей нет, бэкенд сообщает об отсутствующем API.
Автоматически заменять их приблизительной отрисовкой он не будет.

Обычный `state` хранит строку. Ни один режим не обещает сохранение
undo-истории при программной замене текста либо пересоздании поля.
При программной замене выделение сбрасывается, позиция курсора ограничивается
новой длиной текста. Обычная перекомпозиция без замены текста сохраняет
курсор, выделение и историю. Начальные отступы и пустые строки сохраняются.

## Раскладка и обновление параметров

Высота поля зависит от шрифта и числа видимых строк. Для сторонних шрифтов
размер многострочного поля в превью может быть приблизительным - проверяйте
его в игре.

`lines` задаёт высоту видимой области, а не ограничение длины текста.
`height` у оформленных компонентов и `modifier:height()` у BasicTextField
переопределяют её. Длинное содержимое прокручивается нативным textbox.

`wrap` управляет переносом длинных строк в многострочном поле. По умолчанию
перенос включён для обычного текста и выключен при заданной `syntax`.
`UI.Lua` всегда отключает переносы. Если подсветка переключается на лету,
задайте `wrap` явно, чтобы режим переноса оставался прежним.

Изменения текста, обработчиков, цвета, размеров, `hint`, `editable`, `syntax`
и `line_numbers` не пересоздают поле. Изменения шрифта, padding, wrap или
однострочного/многострочного режима требуют пересоздания нативного элемента:
фокус, выделение и undo-история при этом не сохраняются.
Удаление или пересоздание активного поля вызывает `on_defocus` и прекращает
доставку текста прежнему элементу.

Статические превью показывают строки, номера и обрезку, но не нативную
подсветку, взаимодействие, прокрутку или автоматические переносы.
Параметр `presentation`
применяется только в живом интерфейсе VoxelCore: статическое превью его
декорации не воспроизводит.

## Клавиши нативного поля

| Действие | Поведение |
|---|---|
| Выделение мышью, Ctrl+C | Доступно и при `editable=false` |
| Ctrl+A | Выделяет всё; повторное нажатие снимает выделение |
| Ctrl+V, ввод, Backspace | Изменяют редактируемое поле; заблокированы в режиме только для чтения |
| Ctrl+Z / Ctrl+Y | Нативные undo / redo до программной замены текста |
| Стрелки, Shift+стрелки | Перемещение и выделение в редактируемом поле |
| Enter | Однострочное поле вызывает `on_submit`; многострочное вставляет перевод строки |
| Tab | Текущая интеграция Kompot передаёт фокус навигации, не вставляя отступ и не закрывая HUD |
| Escape в HUD-оверлее | Движок закрывает оверлей целиком |

Стрелки и Shift+стрелки в нативном режиме только для чтения ограничены
движком; гарантируются выделение мышью и Ctrl+A. Поле получает текстовые
клавиши вместо контролов Kompot. Горячие клавиши своего мода следует
отключать через `on_focus` / `on_defocus`: BasicTextField не управляет
произвольными обработчиками других модов. Политика навигации зависит от
интеграции поля в HUD.

## Состояние редактора и собственная отрисовка

```lua
local editor = K.text_field_state("local answer = 42")
UI.TextField({
    editor_state = editor,
    lines = 4,
    presentation = {
        spans = {{start = 0, finish = 5, color = "#E3AF67"}},
        selection_color = "#386F94AA",
        caret = {shape = "block", color = "#E3AF6770", blink = 0.5},
    },
})
-- Внешняя замена текста и направленного выделения одним обновлением:
editor.value = {text = "Привет", anchor = 6, caret = 0}
```

Вне композиции используйте `K.new_text_field_state(text)`. Начальное
выделение - `{anchor = 0, caret = 0}`. `editor_state`, `state` и `value`
взаимоисключающие. Снимки заменяются целиком; изменять их поля на месте нельзя.
`anchor` - закреплённый конец выделения, `caret` - движущийся конец.
Индексы начинаются с нуля и используют единицы нативного `caret`, а не байты
UTF-8. Концы за пределами текста ограничиваются движком и синхронизируются
обратно. Поддержка графем, IME и дополнительных Unicode-символов на Windows
этим расширением не добавляется; ограничения нативного ввода сохраняются.

Изменение текста записывает новый снимок перед `on_change(text)`.
Перемещения выделения без редактирования считываются каждый кадр и вызывают
`on_selection_change(anchor, caret)`. Внешняя установка состояния этот callback
не вызывает, кроме нормализации индексов движком.

Диапазоны `spans` полуоткрытые: `[start, finish)`. Последний совпавший диапазон
задаёт цвет; шрифт и размеры символов остаются нативными. `presentation`
заменяет нативную подсветку `syntax`: цвета нужно передать через `spans`.
Текст рисуется только для видимых строк, в обрезанной области поля.
`caret.shape` - `"bar"` (по умолчанию) или `"block"`; `width` задаёт ширину
полоски, `blink` - длительность каждой фазы в секундах, `0` отключает мигание.
`editable=false` сохраняет выделение и копирование, скрывая каретку.

Для своей формы каретки задайте callback, возвращающий `rect`/`text` примитивы
в локальных координатах поля:

```lua
presentation = {
    draw_caret = function(r, context)
        return {{kind = "rect", x = r[1], y = r[2] + r[4] - 2,
            w = r[3], h = 2, color = "#60D5FF"}}
    end,
}
```

`r` - `{x, y, ширина_символа, шаг_строки}`; callback вызывается только в
видимой фазе мигания. Этот API отвечает за оформление, не за обработку ввода.
Выключение `presentation` возвращает нативный рендеринг без пересоздания поля.
