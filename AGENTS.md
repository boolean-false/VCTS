# Правила проекта

- VCTS должен работать со штатным VoxelCore без локальных патчей и изменённых сборок движка.
- VoxelCore распространяется отдельно от игры и не входит в дистрибутив Shmon.
- Не изменять исходники или установленный VoxelCore при доработке VCTS и игр.
- Требуемые изменения движка оформлять через PR в `origin/main` репозитория VoxelCore. До принятия PR использовать штатный API.
- Комментарии в коде и описания писать на русском, кратко и по делу, без длинных тире.
