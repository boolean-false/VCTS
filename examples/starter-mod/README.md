# starter

Универсальный TypeScript-шаблон для VoxelCore 0.32.1.

Начните с [руководства](VCTS_GUIDE.md). Выполните npm install, затем
npm run check, npm run build, npm run watch или npm test.

Toolchain подключается через file:../.. к корню VCTS. При переносе
примера отдельно обновите путь в package.json.
